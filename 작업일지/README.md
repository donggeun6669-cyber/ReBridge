## 작성 규칙

1. 제목 = 그날의 한 줄. 본문은 **무엇을 / 왜 / 다음**.
2. 커밋 해시를 같이 적어 추적 가능하게.
3. 핵심 원칙은 매일 재확인: **추측 주입 금지 · 자료 없으면 "없음"을 정직하게 · 행마다 source.**
4. 관련 상세는 `작업현황/`, `ReBridge_AI공모전용/Data/`, `src/data/HANDOFF.md`에 흩어져 있으니 링크로 연결.
