## 0. 이 문서를 쓰기 전에 — "내가 학교 밖 청소년이라면"

- 나에겐 **담임도, 진학 상담 선생님도, 같이 정보 나눌 반 친구도 없다.**
- 입시 정보를 찾아보면 전부 **'내신', '학생부', '학교장 추천'** 이야기뿐이다. 나한텐 그런 게 없다.
- 검정고시로 대학을 **갈 수 있는지, 수시를 쓸 수 있는지조차 확신이 없다.**
- 나는 정보가 아니라 **"너도 갈 수 있어"라는 확인**과 **"그럼 지금 뭘 하면 돼?"라는 안내**가 필요하다.

> **이 앱의 진짜 역할은 '정보 제공'이 아니라 '번역'과 '동행'이다.**

---

## 1. 프로젝트 개요

**ReBridge**는 학교 밖 청소년이 **검정고시 기준으로** 지원 가능한 대학·전형을 찾고,
전형이 무엇인지 이해하고, 지금 무엇을 준비해야 하는지까지 안내받는 입시 정보 웹 앱이다.

V1에서는 **입시 정보 단 하나의 기능에만 집중**한다. 진로·센터·챗봇은 만들지 않는다.

## 2. 피드백 반영 요약

| 피드백 | 반영 방향 |
| --- | --- |
| 욕심 줄이고 순차 개발 | 입시 정보 하나만, 나머지 전부 삭제 |
| 합/불만 던지는 느낌 | 합/불 → **이유 + 다음 행동**까지 제시 |
| 프로필 기능 부재 | 프로필 입력 → 맞춤 결과가 중심 흐름 |
| 검정고시 실제로 작동하게 | 검정고시생 기준으로 모든 정보 필터·번역 |
| 쉬운 언어 | "몇 % 향상" → "몇 문제 더" 식으로 번역 |
| 지도 API 안 보임 | 센터(지원) 기능 자체를 V1에서 제외 |
| UI 퀄리티 낮음 | 색상·말투·컴포넌트 전면 재설계 |

## 4. 전형 완벽 설명 (★ 추가 — 앱의 교육 콘텐츠 핵심)

이 사용자는 "학종", "교과"가 뭔지부터 모른다.
그래서 **각 전형이 무엇이고, 검정고시 성적을 어떻게 반영하는지**를 앱 안에서 쉽게 설명한다.
(앱 내 '전형이 뭐예요?' 버튼 → 아래 내용을 카드로)

### 4-1. 검정고시생도 수시 지원할 수 있나요? → **네, 할 수 있어요**

> 가장 많이 오해하는 부분. **검정고시생도 대부분의 수시 전형에 지원할 수 있어요.**
> 다만 아래 경우는 지원이 막혀 있어요:
> - **학교장 추천 전형** (재학 중인 학교의 추천이 필요해서)
> - **재학생/졸업예정자 한정 전형** (지역균형 등 일부)
>
> 이 두 가지를 빼면, 학생부종합·논술·정시 등 길은 충분히 열려 있어요.

### 4-2. 전형별 설명 + 검정고시 반영 방식

| 전형 | 한마디로 | 무엇으로 평가 | 검정고시는 어떻게 반영돼요? | 검정고시생에게 |
| --- | --- | --- | --- | --- |
| **학생부교과 (교과)** | 내신 성적표로 뽑아요 | 고교 내신 등급 위주 | **비교내신**으로 환산 (검정고시 점수 → 내신 등급처럼 변환). 대학마다 환산식이 달라요 | 대학에 따라 유·불리 갈림. 환산식 확인 필수 |
| **학생부종합 (학종)** | 성적 말고 '너라는 사람'을 봐요 | 서류(활동·자기소개) + 면접 종합평가 | 검정고시 성적표 + 그 외 활동/서류로 평가 | 내신이 없어도 길이 열려 있어 유리한 편 |
| **논술전형** | 논술 시험 점수로 뽑아요 | 논술고사 위주, 내신 영향 적음 | 내신 비중이 작아 검정고시생 불이익이 적음 | **검정고시생에게 유리할 수 있는 전형** |
| **실기/특기자** | 실기 실력으로 뽑아요 | 예체능 등 실기시험 | 실기 위주, 검정고시 영향 적음 | 해당 분야 지망생만 |
| **정시 (수능위주)** | 수능 점수로 뽑아요 | 수능 점수 | 재학생과 **완전히 같은 조건** | 가장 공평한 길 |

### 4-3. 꼭 알아야 할 두 가지 개념

- **비교내신**: 검정고시생은 내신이 없어서, 검정고시 점수를 내신 등급처럼 바꿔서 봐요. 대학마다 바꾸는 방식이 달라요.
- **수능 최저학력기준**: 수시에 붙어도 "수능에서 이 정도는 나와야 한다"는 조건. 예) '2개 합 5' = 두 과목 등급을 더해 5 이하.

## 5. 핵심 기능 (딱 3개)

### 기능 1. 프로필 입력
부담 없이, 짧게. 모르는 항목은 "아직 몰라요" 허용. 로그인 없이 브라우저 저장(localStorage).
- 검정고시 평균 점수(또는 모름) / 수능 응시 계획 / 희망 지역 / 관심 계열 / (선택) 가고 싶은 대학

### 기능 2. 맞춤 대학 결과 (앱의 심장)
각 대학 카드가 세 질문에 답한다.
> ① 나, 여기 지원할 수 있어? ② 어떤 전형으로? ③ 그럼 지금 뭘 해야 해?(★ 차별점)

```
🟢 OO대학교                                      [지원 가능]
검정고시생도 수시 '학생부종합'으로 지원할 수 있어요.
수능 최저 조건이 있어요: 국·수·영 중 2과목 등급 합 5 이하.

👉 지금 할 일: 모의고사 한 번 풀어서 내 수능 위치부터 확인해보기
```
'불가'도 차갑지 않게 — 항상 대안/다음 스텝 제시.

### 기능 3. 대학 상세 + 수시/정시 가이드
- 전형별 상세(전형 설명 + 검정고시 반영 + 수능 최저 + 면접 유무)
- 비교내신 환산 안내
- "이 대학이 너에게 맞는/안 맞는 이유"
- 수시 vs 정시 검정고시생 특화 가이드
- **대학 위치 지도** (결과/상세에서 어디 있는지 핀으로 표시 — 상세는 13번 TODO)

## 7. 데이터 — 전국 모든 대학 모집요강 (★ 새로 구축)

> 기존 `admissions.json` / `gedRequirements.json`은 **쓰지 않는다.**
> 전국 대학 모집요강을 **검정고시 관점**으로 새로 수집한다.
> 아래는 수집해야 할 **데이터 필드 정의서**다.

### 7-1. 표 A — 대학 기본정보 (universities)

| 필드 | 타입 | 필수 | 예시 | 왜 필요한가 |
| --- | --- | --- | --- | --- |
| `univId` | string | ✅ | `snu` | 대학 고유 ID (전형 표와 연결) |
| `name` | string | ✅ | 서울대학교 | 표시명 |
| `region` | string | ✅ | 서울 | 지역 필터 |
| `establishment` | string | ✅ | 국립 / 사립 | 등록금·성격 참고 |
| `admissionOfficeUrl` | string | ✅ | https://... | 입학처/모집요강 원문 링크(신뢰성) |
| `guidelineYear` | string | ✅ | 2028학년도 | 어느 해 기준인지(정확성) |
| `lat` / `lng` | number | ✅ | 37.45 / 127.1 | **대학 위치 지도 표시에 필요(V1 포함)** |

### 7-2. 표 B — 전형별 상세 (admissions) ★ 핵심

대학 1곳당 여러 행. `univId`로 표 A와 연결.

| 필드 | 타입 | 필수 | 예시 | 왜 필요한가 |
| --- | --- | --- | --- | --- |
| `univId` | string | ✅ | `snu` | 대학 연결 |
| `phase` | string | ✅ | 수시 / 정시 | 시기 구분 |
| `admissionType` | string | ✅ | 학생부종합 / 학생부교과 / 논술 / 실기 / 수능위주 | 전형 유형(설명·필터 핵심) |
| `admissionName` | string | ✅ | 일반전형 | 실제 전형명 |
| `gedEligible` | string | ✅ | 가능 / 불가 / 조건부 | **검정고시 지원 가능 여부(가장 중요)** |
| `gedIneligibleReason` | string | ⬜ | 학교장 추천 필요 | 불가 시 사유(차갑지 않게 설명) |
| `gedReflection` | string | ✅ | 비교내신 환산 / 서류평가 | 검정고시 성적을 어떻게 보는지 |
| `comparativeGrade` | string | ⬜ | 평균 80점→2등급 환산 | 비교내신 환산식(있으면) |
| `evalMethod` | string | ✅ | 1단계 서류100%, 2단계 면접30% | 전형 방법·반영 비율 |
| `interview` | boolean | ✅ | true | 면접 유무 |
| `csatMinimum` | string | ✅ | 2개합5 / 없음 | 수능 최저 조건 |
| `recruitCount` | number | ⬜ | 30 | 모집인원 |
| `competition` | number | ⬜ | 12.3 | 작년 경쟁률(참고) |
| `referenceScore` | string | ⬜ | 검정고시 평균 85+ | 지원 참고선(있으면) |
| `unit` | string | ⬜ | 자유전공학부 | 모집단위/학과 |
| `note` | string | ⬜ | — | 비고 |
| `source` | string | ✅ | 2028 시행계획 p.12 | 출처(신뢰성·검증) |

### 7-3. 수집 시 주의 (검정고시 관점)
- **모든 전형에 대해 `gedEligible`을 반드시 채운다.** 앱의 핵심 분기점.
- `gedReflection`(검정고시 반영 방식)이 비어 있으면 사용자에게 도움이 안 된다.
- `csatMinimum`은 사용자의 '수능 응시 계획'과 직접 연결되므로 필수.

### 7-4. 규모와 우선순위 (현실적 조언)
- 전국 4년제는 약 200곳. 한 번에 다 채우긴 어렵다.
- **권장 순서:** ① 수도권 + 거점국립대 → ② 검정고시 지원 가능 전형이 있는 곳 우선 → ③ 점진 확장.
- 적어도 **정확하면** 가치 있다. 많고 부정확한 것보다 낫다.

> **결정됨:** 등록금·기숙사·장학금 항목은 **넣지 않는다**(V1 범위 밖).
> 단, `lat`/`lng`(좌표)는 지도 기능을 위해 **필수**로 수집한다.
