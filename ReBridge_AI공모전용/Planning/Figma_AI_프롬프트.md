# 검고담임 — Figma AI 입력용 앱 설명서

> 이 파일은 **Figma AI(First Draft / Figma Make)에 붙여 넣는 프롬프트**다.
> 기능 출처: 배포본(`main`) + 리디자인 브랜치(`claude/keumgo-ui-redesign-5eeclc`) + 휴생랩 0925 회의록.
>
> **이 문서는 "무엇이 들어가는지"만 적는다. "어디에 어떻게 놓는지"는 적지 않는다.**
> 지금 UI를 통째로 갈아엎는 중이라, 배치·구조·컴포넌트 모양은 전부 새로 정할 영역이다.
> 순서를 매긴 곳이 있어도 **중요도 순일 뿐 화면상의 위아래가 아니다.**

## 1. 앱 한 줄 소개

**검고담임** — 검정고시생·학교 밖 청소년이 **대학에 가기까지의 길을 혼자서도 따라갈 수 있게 해주는 모바일 웹앱.**

담임 선생님이 없는 아이들에게 담임 역할을 대신한다. 검정고시 일정 안내부터, 내 점수로 갈 수 있는 대학 찾기, 원서·서류 챙기기, 가까운 꿈드림센터 찾기, 같은 처지의 친구들과 이야기하기까지 한 앱에서 끝낸다.

---

## 2. 사용자

- **나이** 만 15~24세. 대부분 고등학교를 자퇴했거나 다니지 않는다.
- **상태** 학교에 소속돼 있지 않아 입시 정보를 물어볼 어른이 없다. 검정고시는 봤거나 볼 예정.
- **감정** "뒤처졌다"는 말에 예민하다. 다그치거나 재촉하는 말투는 쓰지 않는다.
- **기기** 거의 전부 스마트폰. 데이터 아껴 쓰는 사용자가 있다.

---

## 3. 톤 & 카피 규칙 (디자인보다 먼저 지킬 것)

- 말투는 **해요체**. 친근하되 들뜨지 않는다.
- **"뒤처졌다·늦었다·아직 시작도 못 했다" 류 표현 금지.**
- **합격을 보장하는 표현 절대 금지.** 합격 가능성은 늘 "참고용"이라고 쓴다.
- 입시 용어를 그냥 쓰지 않는다. 쓸 때는 옆에 쉬운 말 설명을 붙인다.
- 금융앱 특유의 짧고 단정적인 문구체를 흉내 내지 않는다.
- 이 문서에 나오는 한글 문구는 전부 **예시**다. 더 나은 말이 있으면 바꿔도 된다.

---

## 4. 앱 전제 조건

- **모바일 전용 세로 화면** (390 × 844 기준). 데스크톱 레이아웃 없음.
- **로그인이 없다.** 회원가입·프로필 사진·소셜 로그인 UI를 만들지 않는다. 모든 정보는 기기에 저장된다.
- 화면끼리는 **앞으로 들어가고 뒤로 나오는** 관계다. 하위 화면에서 되돌아 나올 길이 있어야 한다.
- 사용자가 다른 영역을 보다 돌아와도 **보던 화면이 유지된다**(영역별로 기록이 따로 남는다).
- 몰입형 흐름(글쓰기·약관 동의 등)에서는 전역 내비게이션을 감춘다.

## 5. 주요 목적지 5개

앱이 반드시 닿아야 하는 큰 영역이다.
**이걸 하단 탭으로 풀지, 다른 방식으로 풀지, 순서를 어떻게 둘지는 정하지 않았다.** 알아서 정하면 된다.

| 마이페이지 | 내 정보 · 관심 대학 · 약관 |

## 6. 홈에 들어가는 것

홈이 담아야 하는 정보와 기능이다. **배치·크기·강조는 정하지 않았다.**
다만 아래 중요도는 참고해 줘 — ①이 가장 크게 다뤄지길 바라는 것이고, ④는 부수적이다.

### ① 지금 내 상태
- 학년과 사는 지역 (예: "고3 · 경기")
- **둘 다 비어 있는 경우가 기본이다.** 그때는 대신 앱 이름을 보여준다.
- 여기엔 버튼이 없다. 읽는 정보다.

### ② 나의 대입 로드맵 요약 — 홈에서 가장 중요한 덩어리
- **가장 가까운 일정의 D-day** (예: `D-42 검정고시`)
  → **D-day가 아예 없는 상태도 그려야 한다.** 일정이 아직 공고되지 않으면 사라진다.
- 지금 뭘 할 때인지 알려주는 한 문장
- "비슷한 친구들은 지금…" 류의 거드는 한 문장
- **4단계 진행 상태** — `검정고시` → `내 점수` → `대학 찾기` → `원서·서류`
  → 지나온 단계와 지금 단계가 구분돼야 한다
- 전체 로드맵 화면으로 가는 길

### ③ 큰 기능으로 가는 입구 3개
| 입구 | 설명 문구(예시) |
|---|---|
| 꿈드림센터 | 가까운 센터 찾기·지원 혜택 |
| 대학 찾기 | 내 점수로 갈 수 있는 대학 |
| 커뮤니티 | 같은 길 가는 친구들 |

- 이 중 **꿈드림센터가 제일 중요하다.** 셋을 똑같이 다룰지, 하나만 크게 뺄지는 알아서.

### ④ 잔가지 기능
- **담임에게 물어보기** — "용어·자주 묻는 질문"
- 지금은 1개지만 2~3개로 늘어날 수 있다.

> **홈에 만들지 말 것**
> - 마이페이지 입구 (이미 주요 목적지에 있다 — 같은 기능의 입구를 두 곳에 만들지 않는다)
> - 관심 대학 입구 (마이페이지 안에 있다)
> - 검색창 (홈 검색은 뺐다)

> **중요 — 빈 상태가 기본값이다.** 온보딩에서 아무것도 묻지 않아서, 처음 켠 사용자는 학년·지역·점수가 전부 비어 있다. 채워진 홈만 그리면 안 된다. ①이 앱 이름으로 대체되고, ②의 D-day가 없고, 진행 상태가 첫 단계인 홈도 어색하지 않아야 한다.

## 7. 나머지 화면 — 무엇이 들어가는지

### 진입
| 화면 | 들어가는 것 |
|---|---|
| 스플래시 | 로고 한 컷 |
| 온보딩 | **인사 한 장뿐.** 질문하지 않는다. 시작 버튼 하나 |

### 꿈드림센터
- 위치 사용 동의를 묻는 단계 — "내 위치를 사용할까요?" / 허용 · 그냥 볼게요
- **누구나 받을 수 있는 지원** — 지원 이름 + 대상 + 신청처. 항목을 펼쳐 자세히 볼 수 있다
- **내 지역 꿈드림센터** — 센터 이름·주소·전화·거리
- 센터에서 할 수 있는 것: 전화 걸기 / 지도 보기 / 홈페이지 가기
- (지도는 현재 꺼져 있다 — 자리만 있으면 된다)
- 🆕 **쪽지 보내기** — 0925 회의에서 추가 결정. 아직 코드에 없음 → §9 참고

### 진학지원
| 화면 | 들어가는 것 |
|---|---|
| **나의 대입 로드맵** | 단계별 일정 목록. 각 단계에 `지금 여기` / `완료` / `선택` / `공고 전` 표시. **챙길 서류 체크리스트**도 이 화면 안에 있다 |
| **내 점수 입력** | 검정고시 평균 점수 · 합격 회차 · 수능 모의 등급 · "수능 볼 예정 아니에요" 선택 |
| **나와 맞는 대학 (결과)** | 대학 목록 + 각각의 **합격 가능성 5단계**(안정·적정·소신·도전·어려움). 걸러 보기: 유형 · 수능최저 · 지역 · 정렬. 점수가 없으면 "먼저 내 정보를 알려주세요" 빈 화면 |
| **대학 찾기 (탐색)** | 이름 검색 + 조건으로 걸러 보기. 조건 7묶음: 지역(17개) / 학교 종류(4년제·전문대) / 설립 / 전형(교과·종합·논술·실기·수능·일반서류·특별) / 수능최저 / 면접 / 지방거점 |
| **대학 상세** | 대학 이름 · 정보 묶음 3종(공통/세부/추가) · **"담임 한마디"**(그 대학을 검정고시생 눈으로 풀어 준 설명) · 전형 목록 · `검정고시 불가` 표시 · 모집요강 원문 펼쳐 보기 |
| **전형별 지원 가능 여부** | 전형 하나하나가 `가능` / `불가` / `조건부` / `확인 필요` / `정원외` / `자격 제한` 중 무엇인지 한눈에 |
| 제출서류 | 서류 목록 |
| 검정고시 안내 | "검정고시, 이것만 알면 돼요" · **볼 수 있어요 / 볼 수 없어요** 두 경우 대비 · 공식 자료 링크 |

> **상태 표시가 이 앱의 핵심 부품이다.** 아래 7종은 한눈에 서로 구분돼야 한다.
> `가능` `불가` `조건부` `확인 필요` `자료 없음` `수능 최저 충족` `수능 최저 미달`
>
> 특히 **`확인 필요`와 `자료 없음`은 이 앱에서 매우 자주 나온다.** 실패나 오류처럼 보이면 안 되고, "아직 모른다"는 중립적인 느낌이어야 한다.

### 커뮤니티
- 게시판 7개: `🔥 HOT` `자유` `고민(익명)` `질문` `정보` `합격 후기` `꿈드림 후기`
  (+ 센터 인증을 받은 사람에게만 보이는 `우리 센터`)
- 정렬: 전체 / 최신 / 인기
- 글 목록에 보이는 것: 제목 · 본문 미리보기 · 닉네임 · 인증 뱃지 · 공감 수 · 댓글 수 · `답변 완료` 표시
- 글쓰기
- 글 상세: 본문 · 댓글 · 대댓글 · 공감 · 스크랩 · 신고
- **인증 뱃지 3종** — 🎖️ 학교밖 인증 / 🧑‍🏫 꿈드림 선생님 / 🎓 합격 멘토
- 알림 / 내 스크랩

### 마이페이지
- 내 프로필(닉네임·학년·지역)과 수정
- "내 상황" 요약과 다시 고르기
- **관심 대학** — 담아둔 대학 목록 (여기에만 입구가 있다)
- 알아두면 좋아요 — 용어 사전 · 꿈드림센터
- 약관·정책 — 개인정보처리방침 · 이용약관

## 8. 반드시 그려야 하는 상태들

기본형만 그리고 끝내지 말 것. 아래는 각각 따로 한 장씩 필요하다.

1. **처음 켠 상태** — 학년·지역·점수 전부 없음 (홈 / 로드맵 / 결과)
2. **D-day가 없는 로드맵 요약** — 일정 공고 전
3. **결과 빈 화면** — "먼저 내 정보를 알려주세요" + 입력하러 가기
4. **관심 대학 빈 화면** — "아직 담은 대학이 없어요" + 대학 담으러 가기
5. **불러오는 중**
6. **`확인 필요`·`자료 없음`이 섞인 결과 목록** — 실제로는 이게 제일 흔하다

## 9. 아직 정해지지 않은 것 (디자인하면서 같이 정할 것)

- **쪽지 기능** — 0925 회의에서 "꿈드림센터에 쪽지 보내기"가 추가됐는데 **코드에 없고 어디에 둘지도 안 정했다.**
  정할 것 ① 꿈드림센터 안에 넣을지, 홈에도 입구를 둘지
  ② **로그인이 없는 앱이라 "누가 보냈는지"를 어떻게 표시할지** (닉네임만? 연락처를 받을지?)
- **직업 트랙 9화면 · 학습 트랙 2화면** — 현재 꺼져 있다(출시 범위 밖). **일단 디자인하지 않는다.**
- **지도 화면** — 현재 꺼져 있다. 자리만 잡아 두고 실제 지도는 그리지 않는다.
- **진학지원 영역과 홈의 로드맵 요약이 같은 화면으로 간다.** 중복이 거슬리면 홈 쪽을 더 줄여도 된다.

## 10. 확정된 기준값 (2026-09-28 서연님 결정 — 이건 지켜 줘)

### 서체 — IBM Plex Sans KR

- 구글 폰트에 있고, 앱에도 이미 적용했다(`@fontsource/ibm-plex-sans-kr`).
- **굵기는 400 / 500 / 600 / 700 네 단계만 쓴다.**
  이 서체는 **700이 최대**라 800 이상을 쓰면 브라우저가 가짜 굵기를 그려 한글이 뭉개진다.
  피그마에서도 ExtraBold·Black을 고르지 말 것.
- 현재 앱은 700 한 단계에 강조가 몰려 있다(원래 700/800 두 단계였는데 800이 없어서 합쳤다).
  **새 디자인에서 600과 700으로 다시 나눠 주면 좋겠다.**

### 모서리

- **카드·타일·배너 = 18px** — 앱의 `--r-md`가 이미 18px이고 126곳에서 쓰고 있다. 그대로 맞으면 된다.
- 작은 요소(입력창·작은 칩) = 14px (`--r-sm`)
- 큰 시트·모달 = 26px (`--r-lg`)
- 칩·뱃지 = 완전한 알약 모양

### 행간

- **본문 170%**
- 제목은 140~145% (170%는 제목에 쓰면 줄이 떠 보인다)
- 칩·버튼 라벨은 150% 이하
- ⚠️ 현재 앱 코드는 행간이 250곳에 제각각 박혀 있다(1.5가 64곳, 1.6이 43곳…).
  한꺼번에 못 바꿔서 **새 디자인 기준으로만 적어 둔다.**

### 색 (참고값 — 이건 바꿔도 됨)

- 바탕 회백색 `#F7F8FA`
- 포인트 노랑 — 지금 단계, D-day
- 포인트 파랑 — 버튼, 완료 표시

### 아이콘

- 지금은 두 종류가 섞여 있다: 화면 안은 3D 이모지풍, 내비게이션은 2D 선 아이콘.
  **한 종류로 통일하는 걸 권한다.**
