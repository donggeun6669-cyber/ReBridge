# 검고담임 — Figma AI 입력용 앱 설명서

> 이 파일은 **Figma AI(First Draft / Figma Make)에 붙여 넣는 프롬프트**다.
> 기능 출처: 배포본(`main`) + 리디자인 브랜치(`claude/keumgo-ui-redesign-5eeclc`) + 휴생랩 0925 회의록.
> 디자인(색·타이포·레이아웃)은 **서연님이 다시 정한다.** 여기 적힌 색은 "현재 이렇다"는 참고값일 뿐 지켜야 할 값이 아니다.

---

## 1. 앱 한 줄 소개

**검고담임** — 검정고시생·학교 밖 청소년이 **대학에 가기까지의 길을 혼자서도 따라갈 수 있게 해주는 모바일 웹앱.**

담임 선생님이 없는 아이들에게 담임 역할을 대신한다. 검정고시 일정 안내부터, 내 점수로 갈 수 있는 대학 찾기, 원서·서류 챙기기, 가까운 꿈드림센터 찾기, 같은 처지의 친구들과 이야기하기까지 한 앱에서 끝낸다.

---

## 2. 사용자

- **나이** 만 15~24세. 대부분 고등학교를 자퇴했거나 다니지 않는다.
- **상태** 학교에 소속돼 있지 않아 입시 정보를 물어볼 어른이 없다. 검정고시는 봤거나 볼 예정.
- **감정** "뒤처졌다"는 말에 예민하다. 다그치거나 재촉하는 말투는 쓰지 않는다.
- **기기** 거의 전부 스마트폰. 데이터 아껴 쓰는 사용자가 있다.

---

## 3. 톤 & 카피 규칙 (디자인보다 먼저 지킬 것)

- 말투는 **해요체**. 친근하되 들뜨지 않는다.
- **"뒤처졌다·늦었다·아직 시작도 못 했다" 류 표현 금지.**
- **합격을 보장하는 표현 절대 금지.** 합격 가능성은 늘 "참고용"이라고 쓴다.
- 입시 용어를 그냥 쓰지 않는다. 쓸 때는 옆에 쉬운 말 설명을 붙인다.
- 금융앱 특유의 짧고 단정적인 문구체를 흉내 내지 않는다.

---

## 4. 화면 틀

- 모바일 전용 세로 화면 (390 × 844 기준). 데스크톱 레이아웃 없음.
- **하단 탭바 5개** — 탭마다 화면 스택이 따로 있어서, 다른 탭 보다가 돌아오면 보던 화면 그대로다.
- 탭 루트가 아닌 화면(상세·결과·가이드)은 지금 탭 위에 쌓이고 **왼쪽 위 뒤로 버튼**으로 나온다.
- **로그인이 없다.** 회원가입·프로필 사진·소셜 로그인 UI를 만들지 않는다. 모든 정보는 기기에 저장된다.
- 전체화면으로 도는 흐름(글쓰기·약관)에서는 탭바를 감춘다.

### 하단 탭 5개 (홈이 가운데)

| 순서 | 탭 | 아이콘 | 첫 화면 |
|---|---|---|---|
| 1 | 꿈드림센터 | 핀 | 센터 찾기 |
| 2 | 진학지원 | 학사모 | 나의 대입 로드맵 |
| 3 | **홈** | 집 | 홈 |

## 5. 홈 화면 — 위에서부터 5덩어리 (제일 중요)

### ① 인사 헤더
- 윗줄 작은 글씨: `학년 · 사는 지역` (예: "고3 · 경기") — **둘 다 없으면 "검고담임"**
- 큰 제목 2줄: "우리, 대학 / 한번 가 볼까요?"
- 버튼 없음. 우측 상단 아이콘도 없음(마이페이지는 탭에 있다).

### ② 꿈드림센터 배너 — 가로로 긴 큰 버튼 1개
- 제일 중요한 기능이라 혼자 한 줄을 쓴다.
- 구성: 왼쪽 큰 아이콘 / 제목 "꿈드림센터" / 설명 "가까운 센터 찾기·지원 혜택" / 오른쪽 화살표

### ③ 기능 타일 2개 — 2열 그리드
| 타일 | 설명 |
|---|---|
| 대학 찾기 | 내 점수로 갈 수 있는 대학 |
| 커뮤니티 | 같은 길 가는 친구들 |
- 각 타일: 아이콘 + 제목 + 한 줄 설명. 세로로 쌓인 카드형.

### ④ 로드맵 카드 — 홈에서 가장 큰 덩어리
- 우측 상단에 큰 뱃지 아이콘
- 윗줄 좌: "나의 대입 로드맵" / 윗줄 우: **D-day 칩** (예: `D-42 검정고시`)
  → **D-day가 아예 없는 상태도 그려야 한다.** 일정 공고 전이면 칩이 사라진다.
- 큰 문장 1줄(지금 뭘 할 때인지) + 작은 문장 1줄("비슷한 친구들은 지금…")
- **4칸짜리 진행 바** + 각 칸 아래 라벨: `검정고시` / `내 점수` / `대학 찾기` / `원서·서류`
  → 지난 칸은 채워지고, 지금 칸 라벨은 강조된다.
- 맨 아래 "내 로드맵 보기 >"

### ⑤ "지금 바로" — 작은 섹션 제목 + 리스트
- 현재 항목 1개: **담임에게 물어보기** / "용어·자주 묻는 질문"
- 한 줄짜리 가로 리스트 아이템(작은 아이콘 + 제목 + 설명 + 화살표). 항목이 2~3개로 늘어날 수 있게 그려 둘 것.

> **중요 — 빈 상태가 기본값이다.** 온보딩에서 아무것도 묻지 않아서, 처음 켠 사용자는 학년·지역·점수가 전부 비어 있다. 채워진 화면만 그리면 안 된다. 홈은 ①의 윗줄이 "검고담임"이 되고, ④의 D-day 칩이 없고, 진행 바가 첫 칸에 있는 상태로도 어색하지 않아야 한다.

## 6. 나머지 화면 — 무엇이 들어가는지

### 진입 (탭바 없음)
| 화면 | 들어가는 것 |
|---|---|
| 스플래시 | 로고 한 컷 |
| 온보딩 | **인사 한 장뿐.** 질문하지 않는다. "시작하기" 버튼 하나 |

### 탭 1 — 꿈드림센터
- 위치 사용 동의 시트: "내 위치를 사용할까요?" / [허용] [그냥 볼게요]
- 섹션 **"누구나 받을 수 있는 지원"** — 펼침형 리스트(지원 이름 + 대상 + 신청처)
- 섹션 **"내 지역 꿈드림센터"** — 센터 카드 리스트(이름·주소·전화·거리)
- 센터 카드에서: 전화 걸기 / 지도 보기 / 홈페이지
- (지도 화면은 현재 꺼져 있다 — 자리만 잡아 둘 것)
- 🆕 **쪽지 보내기** — 0925 회의에서 추가 결정. 아직 코드에 없음 → §8 참고

### 탭 2 — 진학지원 (대입의 전부가 여기 있다)
| 화면 | 들어가는 것 |
|---|---|
| **나의 대입 로드맵** | 세로 타임라인. 각 단계에 `지금 여기` / `완료` / `선택` / `공고 전` 칩. 아래에 **"챙길 서류" 체크리스트** 섹션이 붙어 있다 |
| **내 점수 입력** | 검정고시 평균 점수, 합격 회차, 수능 모의 등급, "수능 볼 예정 아니에요" 체크 |
| **나와 맞는 대학 (결과)** | 대학 카드 리스트 + 각 카드에 **합격 가능성 게이지**(안정/적정/소신/도전/어려움 5단계). 상단 필터 칩: 유형·수능최저·지역·정렬. 점수가 없으면 "먼저 내 정보를 알려주세요" 빈 화면 |
| **대학 찾기 (탐색)** | 검색창 + 필터 시트. 필터 7묶음: 지역(17) / 학교 종류(4년제·전문대) / 설립 / 전형(교과·종합·논술·실기·수능·일반서류·특별) / 수능최저 / 면접 / 지방거점 |
| **대학 상세** | 대학 헤더 + 탭(공통/세부/추가) + "담임 한마디" 말풍선 + 전형 리스트 + `검정고시 불가` 뱃지 + 모집요강 원문 펼쳐 보기 |
| **전형별 지원 가능 여부** | 표 형태. 각 칸이 `가능` / `불가` / `조건부` / `확인 필요` / `정원외` / `자격 제한` |
| 제출서류 | 서류 목록 |
| 검정고시 안내 | 큰 히어로 "검정고시, 이것만 알면 돼요" + `볼 수 있어요` / `볼 수 없어요` 두 칸 대비 + 공식 자료 링크 |

> **상태 뱃지가 이 앱의 핵심 UI 부품이다.** 다음 7종은 색과 모양이 한눈에 구분돼야 한다:
> `가능` `불가` `조건부` `확인 필요` `자료 없음` `수능 최저 충족` `수능 최저 미달`
> 특히 **`확인 필요`와 `자료 없음`은 이 앱에서 매우 자주 나온다.** 실패나 오류처럼 보이면 안 되고, "아직 모른다"는 중립적인 느낌이어야 한다.

## 7. 반드시 그려야 하는 상태들

Figma AI가 기본형만 그리고 끝내지 않도록, 아래 상태를 각각 한 장씩 만들어 줘:

1. **처음 켠 상태** — 학년·지역·점수 전부 없음 (홈 / 로드맵 / 결과 화면)
2. **D-day 없는 로드맵 카드** — 일정 공고 전
3. **결과 빈 화면** — "먼저 내 정보를 알려주세요" + [정보 입력하기]
4. **관심 대학 빈 화면** — "아직 담은 대학이 없어요" + [대학 담으러 가기]
5. **불러오는 중** — 스켈레톤
6. **`확인 필요` `자료 없음`이 섞인 결과 리스트** — 실제로는 이게 제일 흔하다

## 8. 아직 정해지지 않은 것 (디자인하면서 같이 정할 것)

- **쪽지 기능** — 0925 회의에서 "꿈드림센터에 쪽지 보내기"가 추가됐는데 **코드에 없고 홈에 자리도 없다.**
  정할 것 ① 꿈드림센터 화면 안에 넣을지, 홈 타일을 하나 더 둘지
  ② **로그인이 없는 앱이라 "누가 보냈는지"를 어떻게 표시할지** (닉네임만? 연락처를 받을지?)
- **직업 트랙 9화면 · 학습 트랙 2화면** — 현재 꺼져 있다(v1 범위 밖). 출시에 넣을지 미정이라 **일단 디자인하지 않는다.**
- **지도 화면** — 현재 꺼져 있다. 자리만 잡아 두고 실제 지도는 그리지 않는다.
- **진학지원 탭과 홈 로드맵 카드가 같은 화면으로 간다.** 중복이 거슬리면 홈 카드를 요약만 남기는 방향도 가능.
