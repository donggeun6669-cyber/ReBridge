## 1. 데이터가 흘러가는 길

```
RAW 원문 (모집요강·시행계획·입시결과 PDF/XLSX, 335개 대학)
   │
   ├─ [예전] 파이프라인 v2 (2026-09-02~)  →  앱 JSON (src/data/)  →  지금 앱이 쓰는 것
   │
   └─ [지금] parse_v3 (2026-09-20~)       →  정본 DB (parse_v3.sqlite)  →  (앱 연결 아직 안 함)
```

- **v2** (`data-pipeline/v2/`): 원본 → SQLite(`out/rebridge.db`) → 검증 통과분만 앱 JSON으로 내보내기.
  `export_app.py` · `export_app_2027.py` 등. LLM을 쓰지 않아요(`data-pipeline/v2/README.md`).
- **parse_v3** (`data-pipeline/parse_v3/`, 브랜치 `parse-v3-safeguards`): RAW만을 원천으로 처음부터 다시 파싱.
  정본 DB에 쓰는 길은 두 개뿐이에요.
  - 규칙·조건(모집전형·자격·평가·환산·수능최저·일정·서류) → `agent_out/*.jsonl` → `merge_agent.py`
  - 입시결과 → `parse_results.py`
  - `validate.py`가 "정본의 모든 행에 출처가 있는가"를 강제로 검사해요.
  - ⚠️ `parse_v3/export.py`는 **사람이 검토할 CSV를 뽑는 도구**예요. 앱 JSON을 만드는 스크립트는 아직 없어요.

## 5. 합격 가능성은 어떻게 계산하나 (`src/lib/scoreEngine.js`)

### ① 검정고시 점수 → 비교내신 등급
- 대학마다 검정고시 점수를 몇 등급으로 보는지(비교내신 환산표)가 달라요.
  `comparative_2027.json`에 그 대학 환산표가 있으면 그걸로 계산해요 (`applyComparativeConversion`).
  - 환산표 117개는 전부 '등급표' 형식이에요.
  - 이 중 **평균 점수 → 등급 구간까지 대학 공식인 곳은 31개**예요. **59개는 '등급 → 환산점수'만 공식이고 구간은 앱의 표준 추정**이라 화면에 '추정'이라고 표시해요. 27개는 출처 구분 값이 비어 있어요 `[확인 필요]`.
- **환산표가 없는 대학(64개)은 칸수를 아예 보여주지 않아요.** "입학처에 비교내신 기준을 문의하세요"라고 안내해요.
  - 예전에는 다른 대학 표의 중앙값으로 등급을 만들어 비교했어요. 그러다 성균관대·서강대 같은 곳이 '적정'으로 뜨는 문제가 있어서 2026-09에 막았어요.

### ② 작년 합격선과 비교
- 비교하는 합격선은 **어디가 2026학년도 70%컷**이에요.
  70%컷 = 합격자를 성적순으로 세웠을 때 상위 70% 지점의 등급. 합격자 평균이 아니라 분포의 아래쪽 경계에 가까워요.
- 차이(gap) = 내 등급 − 합격선 등급 (등급은 낮을수록 좋음)

| gap | 칸수 | 화면 문구 |
|---|---|---|
| −1.2 이하 | 5 · 안정 | 합격자 대부분보다 좋은 등급 |
| −0.4 이하 | 4 · 적정 | 합격자 안쪽 등급 |
| +0.2 이하 | 3 · 소신 | 합격선 경계. 안전하다는 뜻은 아님 |
| +1.0 이하 | 2 · 도전 | 아직 거리가 있음 |
| 그보다 큼 | 1 · 어려움 | 지금 점수로는 많이 부족 |

- 기준을 짜게 잡은 이유: 70%컷은 일반고 학생 분포이고, 검정고시생은 비교과·서류를 대체 기준으로 평가받아요.
  그 손실을 알 수 없으니 여유를 두는 쪽으로 잡았어요. 이 이유는 코드 주석에도 적혀 있어요.
- **학생부종합은 '안정'을 주지 않아요** (최고 '적정'). 서류평가를 대체서식으로 받으니 통과 여부를 알 수 없어서예요.
- 2025·2026 두 해 합격선을 같이 보여주지만 **평균 내지 않아요.** 두 해 차이가 1등급 넘으면 '변동 큼'으로 표시해요.

### ③ 칸수를 안 보여주는 경우
| 경우 | 이유 |
|---|---|
| 정시(수능위주) | 수능 점수 기준이라 검정고시 평균으로 비교 불가 |
| 대학 환산표 없음 | 기준이 없으면 계산하지 않음 |
| 특수 자격 전형 | 합격선을 붙일 수 없음 |
| 두 해 모두 합격선 없음 | 비교 대상 없음 |

### ④ 5등급제(2028학년도)
- 합격선은 9등급제(2026학년도) 자료라, **2028학년도 지원자는 이 칸수를 그대로 쓰면 안 된다**고 화면에 알려요(`meta.js`).
  5등급제용 계산은 따로 없어요.

### ⑤ 정직 고지
- 모든 결과는 **참고용**이고 합격을 보장하지 않는다고, 대학 상세·목록 도움말·이용약관에 적혀 있어요.
