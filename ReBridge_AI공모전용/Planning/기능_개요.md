# ReBridge 기능 개요

> 검정고시생·학교 밖 청소년이 "담임처럼" 대학 입시를 안내받는 React(Vite) 앱.
> 핵심 원칙: **규칙 기반(AI 추론 없음) · 추측 주입 금지 · 자료 없으면 "없음"을 정직하게 · 행마다 출처.**
> 라이브: https://rebridge-rho.vercel.app · 최종 갱신: 2026-06-03

---

## 화면(탭) 구조

하단 탭 4개: **홈 · 탐색 · 내 로드맵 · 프로필**. 그 외 화면(상세·결과·지도·관심대학·제출서류·FAQ·정보입력)은 카드/버튼으로 진입.

---

## 기능 목록 (어디서 보이는지 포함)

### 1. 홈
- 위치: 하단 탭 **홈**
- 제목 "우리, 대학 한번 가 볼까요?" + 두 버튼: **내 점수로 대학 찾기**(점수 있으면 결과로, 없으면 정보입력), **그냥 둘러보기**(탐색).
- "담임처럼 챙겨드려요" 카드 → 내 로드맵.
- "궁금한 거, 하나씩" FAQ 카드 10종 → 가이드.

### 2. 내 정보(프로필)
- 위치: 홈 "내 점수로 대학 찾기"(점수 없을 때) / 마이페이지 "내 정보 수정" / 곳곳의 "내 점수 입력".
- 검정고시 **과목별 점수** 입력 → 평균·추정 등급 즉시 표시. 수능 계획·관심 지역·계열 선택.
- "나에게 맞는 길 보기" → 결과 화면. (모든 정보는 이 기기 localStorage에만 저장)

### 3. 대학 탐색 ★최우선 기능
- 위치: 하단 탭 **탐색**
- 전국 **351개 대학**. 이름 검색, 필터(서울/수도권/지방거점/전문대학), 정렬.
- **정렬**: 점수가 있으면 **"가능성순"**(합격 가능성 높은 순), 없으면 추천순 / 가나다순.
- 카드 신호 두 종류(서로 다른 축):
  - **칸수 게이지**(안정·적정·소신·도전·어려움): 내 점수로 본 **합격 가능성**(합격선 자료 있을 때).
  - **검정고시 적합도 칩**(지원 수월·지원 가능·조건 확인): 합격선 자료가 없을 때, **지원하기 좋은 정도**(합격 확률 아님).
- 우상단 **지도** 버튼 → 지도 화면.

### 4. 검정고시 적합도 (비확률적 힌트)
- 위치: 탐색 카드 칩 + **대학 상세**의 각 전형 펼침 "검정고시 적합도" 블록.
- 근거(규칙 기반): 전형 성격(학종/논술/교과/수능) + 비교내신 환산표 유무 + 수능최저 유무.
- 상세에선 사유를 문장으로 풀어주고 "※ 합격 확률이 아니라 지원하기 좋은 정도"임을 명시.

### 5. 칸수 게이지 (합격 가능성)
- 위치: 탐색·결과 카드, 대학 상세 전형 요약.
- 검정고시 평균 → 추정 등급 → 작년(2025) 합격선과 비교 → 5단계 게이지 + 부족 평균점수·과목당 문항수.
- 2025 9등급제 추정 → 2028 5등급제와 제도 달라 **참고용**임을 명시.

### 6. 나와 맞는 대학 (결과)
- 위치: 프로필 제출 후 / 홈 "내 점수로 대학 찾기".
- 프로필 기반 지원 가능 대학을 **가능성순**으로. 카드마다 칸수 또는 적합도.

### 7. 대학 상세
- 위치: 어느 화면에서든 대학 카드/지도 핀 → 상세.
- **담임 한마디**(점수 기반 종합 코칭) + 전형별 펼침: 검정고시 적합도 · 작년 합격선 · 전형 요소(수능최저·면접·모집인원) · 비교내신 가용성 · 전형 방법 · **제출서류 체크리스트**.
- 우상단 **북마크(책갈피)** → 관심 대학에 저장.

### 8. 관심 대학 (북마크)
- 위치: 대학 상세 북마크 버튼으로 담고, **마이페이지 → 관심 대학**에서 목록 확인/삭제.
- 저장: 브라우저 localStorage(`rebridge_bookmarks`), 로그인 없이 이 기기에만.

### 9. 지도
- 위치: 탐색 우상단 "지도".
- 전국 351개 대학 핀(검정고시 전형 유무로 색 구분). 전국 줌에선 점만, **확대하면 학교 이름** 표시. 핀 클릭 → 상세 이동.

### 10. 내 로드맵
- 위치: 하단 탭 **내 로드맵** / 홈 "담임처럼 챙겨드려요".
- **내 상황**: 평균·추정등급 + 안정/적정/소신 대학 수(탐색과 동일 계산) + 바로가기.
- **목표 대학까지**: 관심 대학(북마크)별로 합격선까지 **몇 점·과목당 몇 문제 더** 필요한지, 또는 "지금 점수로 안정권".
- **단계 타임라인**: 검정고시→목표 좁히기→수시→수능→면접→발표·등록→정시. 각 단계 D-day·"지금 여기"·**용어 풀이**(비교내신·수시 6장·수능최저·수시 납치·가나다군)·가이드 링크·맞춤 액션 버튼.

### 11. FAQ / 가이드
- 위치: 홈 FAQ 카드 / 단계의 "자세히 알아보기".
- 주제 10종: 전형 종류, 검정고시 수시, 비교내신, 수능최저, 수시·정시 차이, 수시 횟수, 원서 접수, 면접, 수능 등급, 모집요강 보는 법.

### 12. 담임에게 물어보기 (도움 창구) ★차별화
- 위치: 홈 "막히면 물어보세요 — 담임에게 물어보기" 카드 → `help` 화면.
- **순수 생성형 챗봇을 의도적으로 쓰지 않음** — 입시 사실을 AI가 지어내면 환각이 나고, "추측 금지" 원칙과 충돌하기 때문. 대신 3단:
  1. **능동 안내**: 점수/일정이 있으면 맨 위에 "지금 너에게: {로드맵 다음 할 일}"(로드맵 로직 재사용, 생성 0).
  2. **검색형 FAQ**: "무엇이 궁금해요?" 입력 → 사람이 미리 정리한 10개 가이드를 **키워드 매칭**해 가장 맞는 답을 보여줌(LLM 0·환각 0). 탭하면 가이드로.
  3. **사람 멘토 비동기 Q&A**: 답이 없으면 "멘토에게 직접 물어보기" → **구글폼**으로 질문 접수, 검정고시 출신 선배·멘토가 답변.
- 약속 카피: **"모르면 지어내지 않고, 진짜 사람(멘토)에게 연결해드려요."**
- 차별화: 타 사이트 FAQ는 재학생 기준 → 여긴 검정고시 맥락 전용 / 카페·오픈채팅 익명 답글 ≠ 나를 아는 전담 멘토 / 정보 나열형엔 없는 개인화.
- 설정: 멘토 폼 연결은 `HelpScreen.jsx`의 `MENTOR_FORM_URL` 상수에 구글폼 주소를 넣으면 활성화(비어 있으면 "준비 중" 안내).

## 데이터 (정직성 원칙)
- 대학 기본정보 351곳(교육부 공공데이터, 좌표 100%).
- 전형 데이터: 2028 시행계획 PDF 근거. 핵심 대학은 모집인원·전형방법·수능최저까지 상세.
- 비교내신 환산표 188개 대학(숫자 환산표 77개).
- 작년 합격선(2025): 공개된 자료에 있는 곳만. **없으면 "공개 자료에 없음"을 정직하게 표기**(추측 금지).

## 저장/프라이버시
- 점수·답변·관심대학 모두 **이 기기(localStorage)** 에만. 서버 전송·로그인 없음.
