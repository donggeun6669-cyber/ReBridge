## 0. 디자인 언어 — "친근함 × 신뢰" 결합 (★ 핵심 컨셉)

두 레퍼런스의 **역할을 명확히 분리**한다. (← 팀장 피드백 반영)

### 뼈대·행동 = **토스(Toss)** — 주된 베이스
> 왜 토스인가: "어렵고 무섭게 느껴지던 것(돈·금융)"을 **안전하고 쉽게** 만든 앱.
> 입시도 정확히 같은 문제. **앱이 돌아가는 방식 전부를 토스에서 가져온다.**

- **한 화면에 핵심 행동 하나** (선택지 폭탄 금지)
- 기본적인 **기능 표현 방식**, 정보를 보여주는 방법
- **넉넉한 여백**, 화면 전환·이동 흐름
- 사람 말투의 마이크로카피, **부드러운 존댓말**
- 과장 없는 정보 + **출처/기준일 표기** = 신뢰
- 딱딱한 테두리 대신 부드러운 그림자

### 비주얼 스킨 = **인스타그램** — 겉모습만
> 인스타에서는 **구조나 작동 방식을 가져오지 않는다.** 오직 '감각(보이는 결)'만 빌린다.

- **색감** — 생기 있고 따뜻한, 살짝 그라데이션을 허용하는 색 사용
- **글씨체 느낌** — 둥글고 친근한 현대 산세리프
- **아이콘** — 심플·모던한 라인/필 아이콘
- (피드·스토리·탐색 같은 인스타의 화면 구조는 **따르지 않는다** — 그건 토스 방식으로)

### 결합 한 줄 정의
> **"토스처럼 돌아가고, 인스타처럼 보이는 입시 앱."**

## 1. 디자인 대전제 (공통)

| --- | --- |

## 2. 홈 화면의 목적 — 딱 두 가지

1. **부담 낮추기** — "당장 시작하라"가 아니라 "천천히 둘러봐도 돼요"
2. **자연스럽게 다음으로** — 압박 없는 부드러운 진입

> ❗ 톤 수정: 이전 "검정고시로도 대학 갈 수 있어요 / 지금 시작하기"는
> **시작을 강요하는 느낌**이라 폐기. 부담을 줄이는 방향으로 다시 잡는다.

### 히어로 문구 (확정)

- **메인(큰 글씨):** 우리, 대학 한 번 가 볼까요?
- **보조(한 줄):** 아직 마음 정하지 않아도 괜찮아요. 어떤 길이 있는지부터 천천히 같이 봐요.

> 톤 의도: `우리` = 혼자가 아니라 같이 가는 느낌 / `한 번 가 볼까요?` = 부담 없이 권하는 초대.
> "지금 시작하라"는 압박을 완전히 뺀다.

CTA 버튼 문구도 같은 톤으로(압박 ↓, '같이' 느낌):
- "어떤 길이 있는지 둘러보기" 또는 "같이 둘러보기"

## 3. 홈 화면 구성 (위 → 아래)

```
┌─────────────────────────────┐
│  ReBridge            [🔖]    │  ← 상단 가볍게(저장함 진입)
│                             │
│   우리, 대학               │  ← ① 히어로 (큰 글씨, 확정 문구)
│   한 번 가 볼까요?          │
│   아직 마음 정하지 않아도    │  ← 보조 한 줄(보조색)
│   괜찮아요.                │
│                             │
│  ⟵ 전형이 뭐예요? · 검정고시 수시? · 비교내신? ⟶  │  ← ② 한 입 설명(토스식 섹션, 가로 스크롤)
│                             │
│  ┌───────────────────────┐  │
│  │  나에게 맞는 길         │  │  ← ③ 메인 CTA(코랄, 압박 낮춘 문구)
│  │  살펴보기  →           │  │
│  └───────────────────────┘  │
│                             │
│   미리 둘러보기              │  ← ④ 대학 카드 미리보기(부담 0 입구)
│  ┌───────────────────────┐  │
│  │ 🟢 OO대 · 학종 지원 가능 │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 🟢 OO대 · 논술 지원 가능 │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

### 구성 의도
- **① 히어로**: 28~32px, 700. 안심부터.
- **② 한 입 설명(가로 스크롤)**: '전형이 뭐예요?' 등 짧은 설명을 부담 없이. 입력 전에도 배움. (구조는 토스식 섹션)
- **③ 메인 CTA(토스식 단일 행동)**: 코랄, 풀width, 높이 56px+. 문구는 "같이 둘러보기"로 가볍게.
- **④ 대학 카드 미리보기**: 프로필 안 넣어도 대학 카드 몇 개 보여 호기심 유발 → 자연스럽게 입력으로.
