> 최종 갱신: 2026-07-25 (기획서 v1/v2·기능개요·데이터현황·TODO를 이 한 장으로 통합)

## 1. 제품 정의

**한 줄 정의:** 학교를 나온 청소년에게, 담임이 해주던 일을 대신하는 앱.

검정고시로 대학을 가려는 사람에게는 "내 점수로 어디까지 갈 수 있는지"를 계산해 주고,
취업·진로를 택한 사람에게는 "무엇부터 준비할지"를 짚어 준다.

**말투 원칙:** 부드러운 존댓말("~해요"체). 결과만 던지지 않고 항상 **이유 + 다음 행동**을 함께 준다.
'불가'도 차갑지 않게, 대안과 함께.

- "백분위 92" → "한 과목에서 2~3문제 차이예요"
- "기준 미달" → "조금만 더 하면 돼요. 두 문제 차이예요"

---

## 2. 핵심 원칙 (타협 불가)

1. **규칙 기반.** 점수 분석은 AI 추론이 아니라 공개된 전형 규칙과 실제 입결 데이터로 계산한다.
2. **추측 금지.** 자료에 없는 값은 만들어내지 않는다. 잘못된 값은 빈 값보다 나쁘다.
3. **자료 없으면 "없음"이라고 정직하게 말한다.** ("작년 합격선은 공개 자료에 없어요")
4. **합격 보장 표현 금지.** 2025 입결(9등급제)과 2028 전형(5등급제)은 직접 비교가 불가능하므로
   모든 예측은 "참고용"임을 UI에 명시한다.
5. **모든 사용자에게 모든 기능을 보여주지 않는다.** 상황(persona)에 맞는 것만 노출한다.
6. **데이터 행마다 출처(source)를 남긴다.**

## 3. 사용자 분기 (persona)

상태는 localStorage `rebridge_profile`에 저장되며, 이 값에 따라 탭 구성과 노출 기능이 통째로 달라진다.
로직: `src/lib/persona.js`

```
persona = {
  stage: 'studying' | 'tested',              // 검정고시 공부 중 / 이미 응시(점수 있음)
  goal:  'university' | 'job' | 'undecided', // 대학 / 취업·진로 / 미정
}
```

| goal | 주 동선 |
| --- | --- |
| `university` | 점수 입력 → 대학 탐색·분석 → 로드맵(수시/수능 일정) |
| `job` | 진로 질문 → 직업 탐색 → 훈련·자격 로드맵 → 지원 준비 |
| `undecided` | 양쪽을 모두 가볍게 보여주고 고르게 유도 |

## 4. 기능

### 4-1. 대학 트랙

**대학 탐색** — 전국 351개 대학(4년제 213 + 전문대 138). 이름 검색, 지역·유형 필터, 정렬.
점수가 있으면 "가능성순", 없으면 추천순/가나다순.

카드에 붙는 신호는 서로 다른 두 축이다. 혼동하지 않게 구분해서 표기한다.

- **칸수 게이지** (안정·적정·소신·도전·어려움): 합격선 자료가 있을 때의 **합격 가능성**
- **검정고시 적합도 칩** (지원 수월·지원 가능·조건 확인): 합격선 자료가 없을 때 **지원하기 좋은 정도**. 합격 확률이 아님

**점수 분석 엔진** (`src/lib/scoreEngine.js`) — 이 앱의 심장.
검정고시 과목별 점수를 넣으면 대학별로 다음을 계산한다.

1. **비교내신 환산** — 같은 점수도 대학마다 등급이 다르다. 대학별 환산 결과를 나열하고 유·불리를 비교한다.
   대학 공식 환산표가 있으면 그대로 계산하고, 없으면 표준 추정표로 폴백하되 "참고용"으로 라벨링한다.
2. **합격선까지 몇 점 / 몇 문제** — 부족분을 "사회에서 2문제만 더" 같은 행동 지시로 번역한다. 앱의 시그니처.
3. **과목별 전략** — 검정고시는 과목별 점수가 따로 나오고 연 2회다. 어느 과목을 올리면 환산점수가 가장 많이 뛰는지 짚고, 다음 회차 목표 점수를 제시한다.
4. **칸수·모집 분석** — 모집인원·합격선 분포로 지원 난이도를 표시한다.

**대학 상세** — 담임 한마디(점수 기반 종합 코칭) + 전형별 펼침(검정고시 적합도 · 작년 합격선 · 수능최저 · 면접 · 모집인원 · 전형방법 · 제출서류 체크리스트). 북마크 가능.

**지도** — 전국 351개 대학 핀(카카오맵). 검정고시 전형 유무로 색 구분, 확대하면 학교명 표시.

**내 로드맵** — 검정고시 → 목표 좁히기 → 수시 → 수능 → 면접 → 발표·등록 → 정시.
각 단계에 D-day, "지금 여기" 표시, 용어 풀이(비교내신·수시 6장·수능최저·수시 납치·가나다군), 맞춤 액션.

### 4-2. 취업·진로 트랙

직업 탐색(43개 큐레이션 직업 + 커리어넷 실시간 API), 진로 질문, 직업 상세(하는 일·되는 법),
훈련·자격 로드맵(24개 상세 경로), 지원 준비, 심리검사 안내.

학교 밖 청소년이 실제로 진입 가능한 직업만 골라 담았다.

### 4-3. 공통

- **꿈드림 센터 찾기** — 전국 222개 센터(주소·전화·좌표·지원 혜택 완비)
- **커뮤니티** — 꿈드림 후기 / 이야기 / 우리 센터(인증자 전용). 익명 로그인 + 닉네임
- **담임에게 물어보기** — 생성형 챗봇을 **의도적으로 쓰지 않는다.** 입시 사실을 AI가 지어내면 "추측 금지" 원칙과 충돌하기 때문. 대신 3단 구조:
  1. 능동 안내 — 점수·일정이 있으면 "지금 너에게 할 일"을 로드맵 로직 재사용으로 표시(생성 0)
  2. 검색형 FAQ — 사람이 정리한 가이드 10종을 키워드 매칭(환각 0)
  3. 사람 멘토 Q&A — 답이 없으면 구글폼으로 접수, 검정고시 출신 선배가 답변
  - 약속 카피: **"모르면 지어내지 않고, 진짜 사람에게 연결해드려요."**
- **FAQ/가이드** 10종, **용어 사전**, **제출서류 안내**

## 5. 기술 구조

- **React 18 + Vite 6**, JS/JSX (TypeScript 아님)
- **커스텀 라우터** — react-router 아님. `src/App.jsx`가 `{screen, params}` 스택을 들고
  `goTo()`/`goBack()`을 모든 화면에 prop으로 넘긴다. 새 화면은 `KNOWN_SCREENS`에 등록해야 한다

- **Supabase** — 커뮤니티 백엔드. 키가 없으면 localStorage 목(mock)으로 자동 폴백
- 화면 45개, 코드 스플리팅 적용

## 7. 외부 API 목록과 보호 상태

앱이 실제로 네트워크 호출을 하는 곳은 **3개뿐**이다.

| API | 용도 | 키 | 보호 방식 | 상태 |
| --- | --- | --- | --- | --- |
| 커리어넷 (`career.go.kr`) | 직업 정보·상세 | `CAREERNET_API_KEY` (서버 전용) | 서버리스 프록시(`api/careernet.js`) 경유. 파라미터 화이트리스트 + same-origin 검사 + 분당 30회 제한 + CDN 24시간 캐시. 키는 브라우저에 내려가지 않음 | ✅ 안전 |
| Supabase (`*.supabase.co`) | 커뮤니티·익명 로그인 | `VITE_SUPABASE_ANON_KEY` (공개키) | anon 키는 공개 전제. 모든 접근을 `supabase/schema.sql`의 RLS가 서버에서 통제 | ✅ 안전 (RLS 의존) |
| 카카오맵 SDK (`dapi.kakao.com`) | 지도(대학·꿈드림 센터) | JS 앱키 — `src/lib/kakaoMap.js` | **호출 차단 중** (`MAP_ENABLED = false`) | ⏸️ 일시 정지 |

**카카오맵 키에 대해:** 카카오맵 JS SDK는 브라우저가 직접 SDK를 불러오는 구조라
앱키가 소스에 노출되는 것 자체는 **정상이고 피할 수 없다.** 숨기려 해도 의미가 없다.
대신 카카오는 **허용 도메인 등록**으로 보호한다 — 등록된 도메인에서만 키가 동작한다.

> 확인할 것: 카카오 개발자 콘솔 → 내 애플리케이션 → 플랫폼 → Web →
> 사이트 도메인에 `https://gumgomentor.vercel.app`(+ 개발용 `http://localhost:5173`)**만** 등록돼 있는지.
> 비어 있거나 와일드카드면 제3자가 이 키를 자기 사이트에 붙여 쿼터를 소진시킬 수 있다.

**2026-07-25 현재 지도는 꺼져 있다.** 도메인 등록이 확인될 때까지 SDK를 아예 부르지 않도록
`src/lib/kakaoMap.js`의 `MAP_ENABLED = false`로 차단했다. 부수 효과로 번들 트리셰이킹이 일어나
**앱키 문자열까지 프로덕션 산출물에서 사라졌다**(빌드·라이브 실측 확인).
- 대학 지도 → "지도는 잠시 쉬어 가요" 안내 + 목록으로 돌아가기 버튼
- 꿈드림센터 → 지도 영역만 숨기고 지역 필터·222곳 목록·전화 연결은 그대로 동작
- **다시 켜는 법:** 콘솔에서 도메인 등록 확인 후 `MAP_ENABLED = true` 한 줄만 바꾸면 끝.

**API가 아닌 것:** work24·Q-Net·HRD-Net·큐넷·꿈드림·정부24·NEIS 등 십수 개 도메인이 소스에 등장하지만
전부 사용자를 외부 사이트로 보내는 **단순 링크(href)**다. 키도 없고 네트워크 호출도 하지 않는다.
