## 2. 추출 방식 (추측 금지 준수)

- **comparativeGrade(★최우선)**: `비교내신·검정고시·동등학력·환산·산출` 키워드 페이지의 **원문 발췌**(페이지 번호 명시). 표 수치는 그대로 보존, 길면 2,200자 컷.
- **gedEligible**: patch에서는 **null**. 사유 — `admissions.json`의 per-전형 gedEligible(가능768/불가187/조건부52)이 이미 권위 데이터이며, 시행계획 1차의 university-level 신호로 덮어쓰면 "잘못된 값"이 됨. 대신 검정고시 지원불가/허용 신호는 `note`에 페이지와 함께 기록 → Phase 2 병합 시 전형별 검수용.
- pdfplumber 좌표 텍스트 추출. `get_text` 한글 순서깨짐 회피.

## 3. 행 granularity & 병합 규칙 (Task #13용 메모)

- patch_A는 **대학·캠퍼스 단위 1행** (phase/admissionType/admissionName = null).
