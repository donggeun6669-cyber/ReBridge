# 2028 입시 데이터 추출 — 확정 방법 (검증 완료)

> 작성: 2026-06-02 · 목적: Codex에게 넘길 실행 지시
> 이 문서는 **실제 PDF를 검사한 결과**를 근거로 한다(추측 아님).

---

## 0. 내가 직접 검증한 사실 (★ 방향이 여기서 갈림)

| 항목 | 검증 결과 |
| --- | --- |
| PDF 텍스트 추출 가능 여부 | **185개 중 182개가 텍스트 기반** → 대부분 OCR 불필요 |
| OCR 정말 필요한 PDF | **단 3개**: 경희대학교, 이화여자대학교, 국립순천대학교 |
| 검정고시 키워드 추출 | 정상(가천대 기준 "검정고시" 3회, "최저학력" 28회 잡힘) |
| 파일 구성 | **이미 대학별 1파일 + 이름 정규화됨** → 분할 작업 불필요 |
| HWP/HWPX 29개 | 사용자가 **PDF로 변환 예정** → 변환 후 같은 파이프라인 |
| 전문대 시행계획 PDF | **폴더에 없음**(현재 4년제만) → 아래 6번 참고 |
| 설치된 도구 | PyMuPDF(fitz) ✅ / pdfplumber·pymupdf4llm·Docling·LibreOffice ❌ |

> **결론: "전 PDF OCR"은 과잉이다. 텍스트 추출이 메인, OCR은 3개 예외만.**

## 2. 확정 파이프라인 (4단계)

### Phase A — 로컬 텍스트화 (100% 자동, LLM 없음)
- PyMuPDF로 각 PDF를 **페이지별** 텍스트 추출 → `text/{univId}.jsonl` (각 줄 = {page, text})
- `fitz.TOOLS.mupdf_display_errors(False)`로 폰트 경고 끄기
- 전체 수 분 내 완료. 비용 0.

### Phase B — 근거 페이지 좁히기 (자동, LLM 없음)
페이지 텍스트에서 키워드로 관련 페이지만 추려 `evidence/{univId}.jsonl`에 저장(page = 출처).

| 추출 목표 | 키워드(정규식) |
| --- | --- |
| 검정고시 지원자격 | `지원자격`, `검정고시`, `동등(\s)?학력`, `고등학교 졸업`, `학교장\s?추천`, `졸업예정자` |
| 수능 최저 | `수능\s?최저`, `최저학력기준` |
| 모집인원 | `모집인원`, `모집단위`, `정원` |
| 전형방법 | `전형방법`, `사정방법`, `반영비율`, `면접`, `서류` |

→ 30쪽이 5~10쪽으로 압축. **이 좁힌 조각만 다음 단계로.**

### Phase C — 구조화 (좁힌 페이지만)
**(1) 검정고시 지원 가능 판정 = 규칙(정규식) 우선, 애매한 것만 LLM**
- 한국 시행계획 표준 문구 = `"고등학교 졸업(예정)자 및 법령에 의하여 동등 이상의 학력이 인정되는 자"` → **검정고시 포함 = 기본 '가능'**
- **'불가/조건부'로 뒤집는 예외 패턴**만 잡으면 됨:
  - `학교장(의)? 추천` 필요 → 불가
  - `졸업예정자에 한` / `재학생` 한정 → 불가
  - `검정고시 출신자(의)? 지원(을)? 불가` 명시 → 불가
  - `정규 고등학교 (이수|교육과정)` 요구 → 조건부
  - 지역균형·지역인재 일부 → 조건부(확인)
- 이렇게 하면 **검정고시 가능 여부는 LLM 거의 없이** 일관되게 채워짐.

**(2) 수능최저·모집인원·반영비율 = 좁힌 페이지를 LLM이 JSON으로**
- Tier 1 대학(아래 4번)만 **전 필드** 추출.
- Tier 2는 **gedEligible/gedReflection만** 확정, 나머지는 baseline 유지.
- 표가 깨져 안 잡히면 그 페이지만 pdfplumber 보조.

### Phase D — 병합·검증
- 기존 `admissions.json`(baseline)에 patch **병합**(덮어쓰기 아님, 채우기).
- **행마다 `source`에 `"{대학} 2028 시행계획 p.N"` 필수.** 못 찾으면 baseline 유지.
- 각 행에 `status` 태그 추가 권장: `confirmed`(PDF근거) / `baseline`(규칙만) / `needs_guideline`(세부요강 필요).
- 검증 스크립트(HANDOFF.md 6번) 매번 실행: join 무결, gedEligible 누락 0.

## 3. OCR 필요한 3개 처리 (예외)

대상: **경희대학교 · 이화여자대학교 · 국립순천대학교** (이미지/스캔 PDF)

선택지(셋 중 택1):
1. **수동(가장 빠름, 3개뿐)** — 구글 드라이브 업로드 → 구글 문서로 열기(자동 OCR) → 텍스트 복사. 또는 해당 학교 입학처에서 텍스트 PDF/HWP 재다운로드.
2. `ocrmypdf` + Tesseract(한국어 `kor` 데이터) — 텍스트 레이어 입혀서 같은 파이프라인.
3. 사용자가 HWP→PDF 변환할 때 이 3개도 **원본 한글파일로 다시 받아** 변환하면 텍스트 PDF가 됨(권장).

> 3개뿐이라 자동화 가치 낮음. **1번 또는 3번 추천.**

## 4. 우선순위 (효율 = "많이"보다 "정확한 핵심")

| Tier | 범위 | 추출 깊이 |
| --- | --- | --- |
| **Tier 1 (전 필드)** | 수도권 4년제 + 거점국립대 + 검정고시 지원 많은 30~50곳 | gedEligible·수능최저·인원·반영비율·비교내신 전부 |
| **Tier 2 (핵심만)** | 나머지 4년제 전부 | gedEligible/사유/반영방식만 PDF로 확정, 수치는 baseline |
| **Tier 3 (baseline 유지)** | 전문대 138곳 | 현 baseline(수시 일반 가능+정시 가능) 유지 |

> 공모전 시연엔 **Tier 1을 제대로** 채우는 게 "전국 다 어설프게"보다 낫다.

## 5. 정확도 원칙 (반드시 지킬 것)

1. **모르면 비운다. 절대 지어내지 않는다.** (특히 수능최저·비교내신)
2. **행마다 출처(page) 필수.** 출처 없는 값은 baseline로 강등.
3. 검정고시 판정은 **"기본 가능, 예외만 불가"** — 표준 동등학력 문구가 있으면 가능.
4. `comparativeGrade`(비교내신 환산식)는 **시행계획에 거의 없음** → 대부분 `needs_guideline`. 시행계획에서 못 찾는 게 정상이니 무리해서 채우지 말 것.
5. 변경 후 검증 스크립트 통과 확인.

## 6. 전문대 (결정 필요)

- 현재 폴더엔 **4년제 시행계획만** 있음. 전문대 시행계획은 한국전문대학교육협의회(프로칼리지)에서 **별도 배포**.
- 옵션 A: 전문대도 PDF 수집해 Tier 2 수준 추출.
- 옵션 B(권장, 시간 부족 시): 전문대는 **baseline 유지**. 전문대는 대부분 검정고시 지원 가능(수시 일반전형)이라 baseline 정확도가 4년제보다 높음.
