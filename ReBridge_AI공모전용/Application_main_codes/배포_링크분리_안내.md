# 배포 링크 분리 안내 (수상본 동결 + 본선 수정본 새 링크)

> 목표: **예선 우승 버전은 기존 링크에 그대로 박제**, 본선용 수정본은 **새 링크**로 배포.

## 현재 상태
- 예선 수상본 = Vercel 프로젝트 `rebridge`
  - 링크: `https://rebridge-rho.vercel.app` , `https://gumgomentor.vercel.app`
  - **이 프로젝트에 `vercel --prod`만 다시 안 하면 영구 동결됨** (자동배포 미연결이라 git push로도 안 바뀜)
- git 태그 `award-v1` = 수상본 커밋(e46fbe6) 동결 표식
  - 언제든 복귀: `git checkout award-v1`

## 새 링크로 분리하는 법 (CLI, 한 번만)

`ReBridge_AI공모전용/Application_main_codes/` 안에서:

```bash
# 1) 이 폴더를 '새 프로젝트'에 다시 연결
npx vercel link
#   → Set up "...Application_main_codes"? → Y
#   → Link to existing project? → N (반드시 N!)
#   → What's your project's name? → gumgomentor-beta  (원하는 이름)
#   → In which directory is your code located? → ./   (그대로 Enter)

# 2) 수정본 배포
npm run deploy        # = vercel --prod  → 이제 gumgomentor-beta 로 감

# 결과 링크: https://gumgomentor-beta.vercel.app
```

이때부터 `npm run deploy`는 **새 프로젝트(gumgomentor-beta)** 로만 배포됩니다.
수상본(`rebridge`)은 손대지 않으므로 그대로 살아 있습니다.

## 환경변수(서버리스 API) 재설정
새 프로젝트엔 환경변수가 없으니, AI/커리어넷 기능을 쓰면 Vercel 대시보드에서 다시 등록:
- 프로젝트 `gumgomentor-beta` → Settings → Environment Variables
- `GEMINI_API_KEY`, `CAREERNET_API_KEY` (VITE_ 접두어 **없이**, 서버 전용)

## 주의
- `gumgomentor-*-<hash>.vercel.app` 같은 **해시 URL은 그 빌드에 영구 박제** → 공유/북마크 금지. 항상 `gumgomentor-beta.vercel.app`(기본 alias) 공유.
- 배포 후 화면이 안 바뀌면 캐시 → 시크릿창 또는 `npm run verify`.
