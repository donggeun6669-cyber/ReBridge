## 0. 너의 역할 (한 줄)

검정고시생 입시 안내 앱 **ReBridge**의 충남대학교(`univId="cnu"`) 전형 데이터가 **자동추출 상태로 품질이 낮다.**
2028학년도 시행계획 PDF 원본을 보고 **수시 학생부종합·학생부교과 전형을 깨끗하게 재추출**해서, 추측 없이 정확한 patch 파일로 만들고 검증·병합까지 한다.

---

## 1. 작업 전 필수 (사고 방지)

1. **시작 전 `git pull`**, 끝나고 **`git push`** (작업 유실 방지 — 실제로 겪은 사고).
2. 원본 데이터(`admissions_2028.json` 등)를 **직접 수정하지 말 것.** 반드시 별도 `admissions_2028_patch_E.json` 만들고 merge 스크립트로 병합.
3. **추측 금지.** PDF에 없는 값은 `null`/`""`. 잘못된 값은 빈 값보다 나쁘다.
4. 모든 행에 `source`(대학·페이지) 기록.
5. Windows 콘솔 한글 깨짐 → 파이썬 실행 시 `PYTHONIOENCODING=utf-8` 붙이고, 콘솔 출력이 깨지면 결과를 UTF-8 파일로 떨군 뒤 읽어라.

## 2. 지금 무엇이 문제인가 (현황 진단)

`admissions_2028.json`에서 `univId="cnu"` 행은 **26개 있으나 모두 자동추출 품질**이다:

- `recruitCount`(모집인원)가 **전부 null**.
- `csatMinimum`(수능최저)·`evalMethod`(전형방법)가 **PDF 원문이 잘려 들어간 쓰레기 문자열** (예: `"선발비율 학교생활기록부 수능최저학력 구분 선발단계 교과성적 면접 "` 처럼 표 헤더가 그대로 박힘).
- **오분류 행 존재**:
  - `admissionName == "목 차"` 가 `학생부종합/조건부`로 잡혀 있음 → **삭제 대상**(전형 아님, 목차임).
  - `"수능 지역의사선발"`, `"수능 농어촌학생·저소득층학생"`, `"수능 국가안보융합"` 등 **수능(정시·수능위주)** 인데 `phase="수시"` 또는 `admissionType="학생부종합"`으로 잘못 분류됨 → 유형 교정 필요.
- `gedEligible`(검정고시 가능/조건부/불가) 판정은 **대체로 맞지만 재확인**.

원본 PDF: `src/data/pdf_sources/2028/충남대학교[대전][본교]_2028_시행계획(1차수).pdf`
(※ `pdf_sources/`는 git 제외 대상이라 로컬에만 있음. 없으면 먼저 사용자에게 요청.)

## 3. 목표 (이번 작업의 산출물)

충남대 **수시 전형**을 우선순위로 정확히 재구성한다. 전형별로 다음 필드를 PDF 근거로 채운다:

| 필드 | 의미 | 채우는 법 |
| --- | --- | --- |
| `phase` | 수시/정시 | 시행계획 모집시기 |
| `admissionType` | 학생부종합/학생부교과/수능위주/논술/실기·실적 | 전형 분류 정확히 |
| `admissionName` | 전형명 | 정식 명칭(예: "학생부종합Ⅰ 서류") |
| `recruitCount` | 모집인원(합계) | 전형별 요약표에서 숫자. 모집단위별만 있으면 합산, 불명확하면 null |
| `csatMinimum` | 수능최저 | "적용 안 함" / "있음(요강 확인)" / 구체 기준. **원문 잘림 금지 — 사람이 읽을 한 줄로 정제** |
| `interview` | 면접 유무 | true/false |
| `evalMethod` | 전형방법(반영비율) | "서류 100%" / "1단계 서류 N배수 → 2단계 면접 N%" 처럼 **정제된 한 줄** |
| `gedEligible` | 검정고시 가능/조건부/불가 | 시행계획의 검정고시 지원자격·비교내신 유무로 판정 |
| `gedIneligibleReason` | 조건부/불가 사유 | 조건부·불가일 때만 |
| `source` | 근거 | `"2028 충남대 시행계획 pN"` |
| `status` | `confirmed_detail` | 사람이 검수했으니 confirmed_detail |

우선순위: **① 학생부종합(검정고시에 가장 유리) → ② 학생부교과(비교내신 적용) → ③ 정시/수능위주(유형만 교정).**
실기/실적·예체능은 시간 남으면.

## 4. 워크플로 (기존 patch_D 패턴 그대로)

1. **PDF 정독** — `extract_pdf_text.py`로 페이지 텍스트를 뽑고, 전형별 요약표 페이지를 사람이 읽어 모집인원·전형방법·수능최저를 확인.
   (충남대는 전형별로 p.7~p.37에 흩어져 있음. `source` 페이지가 기존 행에 남아 있으니 출발점으로 써라.)
2. **patch 파일 작성** — `admissions_2028_patch_E.json` (배열). 기존 cnu 26행을 **교체할 깨끗한 행**으로 새로 작성. 각 행에 `"univId":"cnu"`, `"_patch":"E"`, `status:"confirmed_detail"`.
   - "목 차" 같은 비전형 행은 **포함하지 않음(=삭제 효과)**.
   - 모르면 비운다.
3. **merge 스크립트** — `merge_2028_patchD.py`를 본떠 `merge_2028_patchE.py`를 만들되, 이번엔 **cnu 기존 행을 patch_E 행으로 replace**(append 아님). `--write` 없으면 dry-run 으로 diff만 출력.
4. **검증** — 병합 후 `HANDOFF.md` 6번의 무결성 체크 실행:
   - orphans=∅, univ-no-adm=∅, `gedEligible` 빈 값 0.
   - cnu 행 수·유형 분포를 before/after로 출력.
5. **리포트** — `src/data/reports/cnu_detail_report.md`에 무엇을 바꿨는지(삭제/교정/보강 행수, 출처 페이지) 기록.
6. **앱 확인** — `npm run dev` 후 충남대 상세 화면에서 모집인원·전형방법이 정상 노출되는지 눈으로 확인.
7. **커밋·푸시.**

## 5. 검정고시 판정 기준 (앱 원칙과 일치시킬 것)

- **학생부종합 = 가능**(서류·면접 기반, 검정고시생 비교내신으로 지원 가능)이 기본.
- **학생부교과 = 조건부/가능** — 충남대는 검정고시 합격 평균점수를 비교내신으로 환산하는 식이 있음(comparative_2028.json의 cnu 항목 참고). 환산식 있으면 `가능`, 자격 제한 단서 있으면 `조건부`.
- **의예·지역인재·지역의사·기회균형** 등은 **자격 제한**(지역/소득/재직 등)이 있으면 `조건부`로 두고 `gedIneligibleReason`에 한 줄.
- **수능최저가 매우 높은 전형**(의대 등)도 가능 여부 자체는 별개 — 자격은 가능이되 csatMinimum에 명시.
