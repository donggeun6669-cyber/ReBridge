# 2028 가천대학교 상세 전형 반영 결과

> 작성일: 2026-06-02  
> 목적: 자동 표 추출이 정확히 성공한 가천대학교를 실제 앱 데이터에 반영한 기록

---

## 1. 한 일

가천대학교는 2028 시행계획 PDF의 전형별 요약표가 표 구조로 정확히 추출됐다.

그래서 기존 `admissions.json`에 있던 가천대학교 baseline 4행을 제거하고, 실제 전형명별 상세 행 19개로 교체했다.

---

## 2. 반영 결과

| 항목 | 값 |
| --- | ---: |
| 제거한 기존 가천대 baseline 행 | 19행 |
| 새로 반영한 상세 전형 행 | 19행 |
| 전체 admissions 행 수 | 957행 |
| 데이터 검증 | 통과 |

주의: 처음에는 baseline 4행을 상세 19행으로 교체했으나, 재실행 가능한 스크립트 구조상 이후에는 기존 가천대 19행을 다시 19행으로 교체한다.
