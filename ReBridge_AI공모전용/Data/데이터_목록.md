# ReBridge 데이터 목록

현재 앱에서 사용 중인 데이터 파일 및 API 전체 정리.  
경로 기준: `src/data/` (정적 JSON), `src/api/` (외부 API)

---

## 1. admissions.json

**경로:** `src/data/admissions.json`  
**형태:** JSON 배열 (`[ {...}, {...}, ... ]`)  
**용도:** 대학별 입시 정보 표시, 지도 핀 배치, 검정고시 지원 가능 여부 필터링

### 주요 필드 (행/열)

| 필드명 | 타입 | 설명 |
|--------|------|------|
| `name` | string | 대학명 (예: 가천대) |
| `location` | string | 지역 간략 표기 (예: 경기) |
| `sido` | string | 시도 전체 명칭 (예: 경기도) |
| `line` | string | 성적대 구분 (상위권 / 중위권 / 하위권) |
| `lat` | number | 위도 (지도 핀 좌표) |
| `lng` | number | 경도 (지도 핀 좌표) |
| `rollingRows` | number | 수시 총 모집인원 |
| `regularRows` | number | 정시 총 모집인원 |
| `rollingCut` | number | 수시 내신 컷 (등급) |
| `csatCut` | number | 수능 최저 점수 기준 |
| `competition` | number | 경쟁률 |
| `departments` | string[] | 검정고시 지원 가능 학과 목록 |
| `ged.status` | string | 검정고시 지원 가능 여부 (가능 / 불가 / 조건부) |
| `ged.eligible` | boolean | 검정고시 전반 지원 가능 여부 |
| `ged.eligible_transfers` | string[] | 지원 가능한 전형 목록 |
| `sourceRows` | object[] | 원본 입시 데이터 (전형별 세부: type, department, admission, cut, competition) |

### 현황
- 약 570개 수시 행, 32개 정시 행 기준으로 구성
- 데이터 출처: 대학별 입시결과 수동 수집 (2025~2026 기준)
- **재수집 필요:** 최신 입시 결과로 업데이트 예정

## 2. gedRequirements.json

**경로:** `src/data/gedRequirements.json`  
**형태:** JSON 객체 (대학명을 key로 사용)  
**용도:** 대학별 검정고시 지원 가능 전형 상세 안내, 전형 필터링

### 주요 필드

| 필드명 | 타입 | 설명 |
|--------|------|------|
| `status` | string | 검정고시 지원 가능 여부 요약 |
| `general_eligible` | boolean | 일반전형 지원 가능 여부 |
| `eligible` | boolean | 전체 지원 가능 여부 |
| `eligible_transfers` | string[] | 지원 가능한 전형 이름 목록 |
| `ineligible_transfers` | string[] | 지원 불가한 전형 이름 목록 |
| `conversion_note` | string | 검정고시 성적 반영 방법 비고 |
| `csat_min` | string | 수능 최저 요건 여부 |
| `transfers` | object[] | 전형별 상세 정보 (아래 참조) |
| `source` | string | 데이터 출처 문서명 |
| `name` | string | 대학명 |

### transfers 내부 필드

| 필드명               | 타입     | 설명                      |
| ----------------- | ------ | ----------------------- |
| `phase`           | string | 전형 시기 (수시 / 정시)         |
| `name`            | string | 전형명                     |
| `eligible`        | string | 검정고시 지원 가능 여부 (가능 / 불가) |
| `conversion`      | string | 성적 반영 방법                |
| `record_ratio`    | string | 학생부 반영 비율               |
| `interview_ratio` | string | 면접 반영 비율                |
| `csat_min`        | string | 수능 최저 요건 (있음 / 없음)      |

### 현황
- 수록 대학: 서울대, 연세대, 고려대, 성균관대, 한양대, 서울시립대, 국민대, 건국대, 가천대, 경기대, 한성대, 부산대, 충남대, 전남대, 청주대, 동의대, 조선대 등
- 데이터 출처: 2028학년도 입학전형 시행계획 수동 수집
- **재수집 필요:** 대학 수 확대 및 최신 시행계획 반영 예정

## 3. centers.json

**경로:** `src/data/centers.json`  
**형태:** JSON 배열 (`[ {...}, {...}, ... ]`)  
**용도:** 학교밖청소년지원센터 위치 안내, 지역별 검색 및 지도 표시

### 주요 필드

| 필드명 | 타입 | 설명 |
|--------|------|------|
| `id` | number | 센터 고유 ID |
| `name` | string | 센터명 |
| `sido` | string | 시도 (예: 서울특별시) |
| `sigungu` | string | 시군구 (예: 중구) |
| `zipcode` | string | 우편번호 |
| `address` | string | 전체 주소 |
| `phone` | string | 전화번호 |
| `homepage` | string | 홈페이지 URL (없으면 "비어있음") |

### 현황
- 전국 학교밖청소년지원센터 전체 수록
- 데이터 출처: 여성가족부 / 커리어넷 공공데이터
- 비교적 안정적인 데이터이나 폐관/이전 여부 주기적 확인 필요

## 4. 커리어넷 API

**경로:** `src/api/careernet.js`  
**형태:** 외부 REST API 호출  
**키:** `VITE_CAREERNET_API_KEY` (`.env` 파일에 보관)  
**용도:** 진로·직업 정보, 학과 정보 등 실시간 조회

### 사용 방식
- 앱 내 진로 탐색 기능에서 호출
- API 키 재발급 불가 → **현재 키 유지 필수**

---

## 5. Gemini API

**경로:** `src/api/gemini.js`  
**형태:** Google Generative AI REST API 호출  
**키:** `VITE_GEMINI_API_KEY` (`.env` 파일에 보관)  
**용도:** AI 챗봇 기능 — 검정고시 준비, 입시 상담 등 자연어 질의응답

### 사용 방식
- 사용자가 채팅창에 질문 입력 시 Gemini 모델에 전달
- 프롬프트 컨텍스트: 학교밖청소년 대상 입시·진로 상담 특화

---

## 데이터 재수집 우선순위

| 우선순위 | 데이터 | 이유 |
|----------|--------|------|
| 높음 | `admissions.json` | 입시 결과 연도별 변경, 대학 수 확대 필요 |
| 높음 | `gedRequirements.json` | 대학 수 부족, 최신 시행계획 반영 필요 |
| 낮음 | `centers.json` | 상대적으로 안정적, 주기적 확인만 필요 |
