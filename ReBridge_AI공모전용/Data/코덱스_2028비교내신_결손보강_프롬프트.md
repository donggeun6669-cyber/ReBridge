## 4. 파이프라인 (결정론 우선, LLM 최소)

0) **인벤토리**: `pdf_sources/2028/` 스캔 → 파일명→univId 매칭. **§6 타깃 46개 + §6 재확인 11개 + 매칭실패 3개**가 대상. (나머지 PDF는 이미 patch_A/B/C에 반영됨 → 건드리지 말 것.)
1) **로컬 추출(LLM 0회)**: pdfplumber 좌표 기반 텍스트. `get_text` 한글 순서깨짐 회피(좌표 정렬). 표는 원문 그대로 보존.
2) **키워드 앵커링** — 다음 앵커가 든 페이지만 발췌:
   `["비교내신","검정고시","동등학력","환산","산출","등급별","반영점수","환산점수","Zone","지원자격"]`
3) **comparativeGrade 발췌**: 앵커 페이지 **원문**을 페이지번호(`[p.NN]`) 붙여 발췌. 표 수치 그대로. 길면 2,200자 컷. 연속 중복 세그먼트만 무손실 축약.
4) **분류 태그** `comparativeGradeType` (병합 시 `merge_2028.py`의 classify와 동일):
   - 숫자 3개 이상 연속(`\d{2,4}[\s,]+\d{2,4}[\s,]+\d{2,4}`) → `numeric_table` (★점수엔진 1차 연결 대상)
   - "모집요강"+("공지/참고/확인") → `deferred`
   - "지원할 수 없/지원 불가" → `ged_block`
   - "비교내신/환산/등급별/산출" → `comparative_prose`
   - 동등학력·지원자격 위주 → `eligibility_prose`
   - 없음 → `none(null)`
5) **이미지 PDF(텍스트레이어 거의 없음)**: 따로 표시. Apple Vision OCR이 한글 깨지면(일부 임베디드 폰트) **무리한 추측 금지**, note에 "이미지PDF/OCR실패 → 모집요강 deferred"로 기록. (선례: 경희대·이화여대)
