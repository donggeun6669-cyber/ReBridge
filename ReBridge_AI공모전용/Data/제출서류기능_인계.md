## ② `getDocuments` 시그니처 / 반환형

```js
import { getDocuments } from '../lib/documents.js';

// 입력: admissions.json 행 1개
//   { phase, admissionType, admissionName, gedEligible, interview, csatMinimum, comparativeGrade, univId }
// 반환:
{
  eligible: boolean,                       // gedEligible==='불가' → false
  common: [{ id, label, required }],       // 검정고시생 공통 서류
  byType: [{ id, label, required }],       // 전형 유형별 서류/응시
  notes: string[],                         // 단정 못 하는 것 = "모집요강 확인"
  confidence: 'general' | 'check',         // 'check'면 "모집요강 확인" 배지 노출
}
```

null/누락 필드 가드 있음(`getDocuments(null)`도 안전). 컴포넌트도 동일하게 가드.

### 적용한 규칙(근거 있는 일반 규칙만)
- **공통**: 검정고시 합격증명서·성적증명서·응시원서·(해당 시)주민등록초본.
- **학생부종합**: 자기소개서 **폐지(2024~)** 미포함. 학생부 대체서식 + "활동증빙은 대학별 → 모집요강 확인".
- **학생부교과**: 검정고시 성적 → 비교내신 환산, 별도 내신 서류 없음 안내. `comparativeGrade` 있으면 환산기준 존재 안내, 없으면 `confidence:'check'`.
- **논술/실기**: 고사 응시 중심. 실기 종목별 증빙은 모집요강 확인(`check`).
- **수능위주(정시)**: 제출서류 최소(`general`).
- **일반(서류)**: 대학별 상이 → 모집요강 확인(`check`).
- **부가**: 면접 있음 / 수능최저 있음(수시) / 조건부 자격 → 각각 note 추가.

> 원칙: 학교 고유 서류 데이터가 없으므로 **만들어내지 않고** 유형 기반 일반안내 + "모집요강 확인"으로 정직하게.

## ③ 메인이 해야 할 통합 단계 (제안)

이 기능은 **연결 전까지 번들/런타임에 영향 없음**(아무 데서도 import 안 됨). 통합은 메인 담당.

### A. DetailScreen 임베드 (가장 자연스러움)
`src/components/DetailScreen.jsx`의 전형 카드(`okRows.map(...)`) 내부, `evalMethod` 출력 아래에 한 줄 추가:

```jsx
import DocumentsChecklist from './DocumentsChecklist.jsx';
// ...전형 카드 안, r(adm 행)을 그대로 전달:
<DocumentsChecklist adm={r} />
```

- `DocumentsChecklist`는 자체 CSS를 직접 import하므로 styles.css 수정 불필요.
- 카드마다 펼치면 길어질 수 있어 "제출서류 보기" 토글/아코디언으로 감싸는 걸 추천.

### B. (선택) 독립 화면 라우트
풀스크린으로 쓰려면 `App.jsx`에 화면 분기 추가:

```jsx
import DocumentsScreen from './components/DocumentsScreen.jsx';
// ...
{screen === 'documents' && (
  <DocumentsScreen
    goTo={goTo}
    univId={params.univId}
    univName={params.univ}
    admissionName={params.admissionName}
  />
)}
```

진입은 DetailScreen 전형 카드에서:
```jsx
<button onClick={() => goTo('documents', { univId, admissionName: r.admissionName })}>
  제출서류 체크리스트
</button>
```

- `DocumentsScreen`은 `getUniversityDetail(univId)`로 행을 찾고, `admissionName` 일치 행(없으면 첫 행)을 `DocumentsChecklist`에 넘김.
- `'documents'`는 메인 화면이 아니므로 `TAB_ROOTS`/`isMainScreen`엔 넣지 말 것(현재 App.jsx의 "준비 중" 폴백 조건도 확인 필요).

### C. 체크 상태 저장
체크박스는 `localStorage` key `rebridge_docs_<univId>_<admissionName>`에 저장됨(adm에 `univId`+`admissionName` 있을 때만). 별도 작업 불필요.
