## 2. 두 갈래 작업

### 2-A. 비교내신 추가 (이게 메인)

**현황:** `comparative_2028.json` 커버리지 **187/351 대학**. `pdf_sources/2028/`엔 **213개 PDF**.
→ PDF는 있는데 comparative 항목이 없는 대학이 다수. 그들을 추출해 채운다.

**데이터 스키마** (기존 항목과 동일하게):
```json
"<univId>": {
  "comparativeGrade": "<PDF에서 뽑은 환산표/환산식 원문(여러 줄 가능)>",
  "comparativeGradeType": "numeric_table | comparative_prose | deferred | eligibility_prose | ged_block | none",
  "source": "2028 <대학명> 시행계획 p.<쪽>"
}
```

`comparativeGradeType` 판정 규칙:
- `numeric_table` — 검정고시 점수 → 환산점수/등급 **표나 산출식이 구체적으로** 있음 (가장 가치 높음).
- `comparative_prose` — 환산 안내가 **글로만** 있고 표는 없음.
- `deferred` — "환산점수표는 모집요강에서 공지" 식으로 **미룸**.
- `eligibility_prose` — 지원 자격 안내 위주.
- `ged_block` — 검정고시 지원 **제한/불가** 단서.
- `none` — 언급 없음 → **항목 자체를 만들지 않음**.

**작업 절차:**
1. `comparative_2028.json` 키 목록과 `universities.json`을 대조해 **comparative 없는 univId** 목록을 뽑는다.
2. 그중 `pdf_sources/2028/`에 PDF가 있는 대학을 우선. **검정고시 지원 많은 곳(수도권·거점국립·중상위)부터.**
3. `extract_pdf_text.py`로 텍스트 추출 → "검정고시", "비교내신", "환산점수", "환산점", "기본점수" 키워드 페이지를 찾아 정독.
4. **명시된 환산표/식이 있으면** `admissions_2028_patch_E_comp.json`에 항목 추가. 없으면 건너뛴다(none은 안 만듦).
5. `merge_2028_patchD.py`를 본떠 `merge_comp_patchE.py` 작성:
   - additive(기존 항목 무회귀), 충돌 시 `comparativeGradeType` 우선순위(numeric_table > prose > deferred > ...) 높은 쪽 유지, 동률이면 새 patch 우선.
   - 빈 `comparativeGrade`는 **절대 lookup에 넣지 않음.**
   - `--write` 없으면 dry-run.
6. 병합 후: comparative 총 개수, numeric_table 개수 before/after 출력. `reports/comparative_patchE_report.md`에 추가한 대학 목록·출처.

**이미지/OCR 의심 1건:** 이화여대 등 텍스트 추출 실패분은 OCR(`ocr_recover_b.py` 참고) 재시도 검토. 실패하면 건너뛰고 리포트에 "OCR 필요"로 남긴다.

### 2-B. 작년 합격선(cutlines_2025) — **결론: null 유지가 정답** (작업하지 말 것, 감사만)

- 현재 보유 118 / 결손 233. 결손 233 중 **232개는 raw `results_2025.json`(20,830행/114대학)에도 행이 없음** = 2025 대입전형결과(대교협) PDF 자체에 미수록.
- 즉 **현재 소스로는 못 채운다. 추측으로 채우면 안 된다 → null 유지.**
- 유일하게 해볼 것: 34개 입결 PDF **커버리지 재감사**로 누락분 일부 회수 가능성만 확인(있으면 patch, 없으면 그대로 둠).
- 새 입결 소스(대학별 공시/진학사·유웨이)가 생기기 전에는 **추가 채움 금지.** 앱은 자료 없을 때 "공개된 자료에 없어요"로 정직 표기 중이며 이게 맞다.

## 3. 검증 (병합 후 매번)

```
python -c "import json;from collections import Counter; \
U=json.load(open('universities.json',encoding='utf-8')); \
A=json.load(open('admissions_2028.json',encoding='utf-8')); \
uids={u['univId'] for u in U}; \
print('orphans',{r['univId'] for r in A}-uids); \
print('missing gedEligible',sum(1 for r in A if not r['gedEligible']))"
```
정상: orphans=set(), missing=0. comparative는 키가 전부 universities.json의 univId에 존재하는지 확인.
