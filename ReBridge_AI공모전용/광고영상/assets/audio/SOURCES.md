## 효과음 — 직접 만든 소리

효과음은 **전부 `tools/make-audio.py`가 계산해서 만든다.** 내려받은 효과음 파일은 없고, 저작권 문제가 생길 소지도 없다.

| 소리 | 만드는 방법 |
|---|---|
| 종이 카드 등장 | 잡음(noise)을 1.5~5kHz만 남기고 40ms 안에 사라지게 |
| 폰 상승 / 공간 확장 / 캠퍼스 선 | 잡음의 중심 주파수를 시간에 따라 올리는 방식(짧은 구간마다 주파수를 바꿔 이어 붙임) |
| 탭·입력 틱 | 부드러운 사인파(720Hz·1.4kHz)에 아주 짧은 감쇠. 시작·끝을 완만하게 해 '딸깍' 잡음 제거 |
| 안착음·체크 | 사인파 2개를 겹쳐 짧게. 체크는 낮은음 → 높은음 |
| 23초 전환 | 짧게 빨아들이는 잡음 스윕 + 아주 낮은 소리 한 번(작게) |
| 잔향 | 지수적으로 줄어드는 잡음으로 만든 임펄스 응답에 합성곱(0.6초), 아주 옅게 |

모든 효과음은 시작·끝에 5ms 이상의 완만한 구간을 넣어 클릭 잡음이 생기지 않게 했다.
