# 검고담임 광고 영상 (EXPO·발표용)

50초 · 1920×1080 · 자동 재생 HTML 모션그래픽. 서비스 앱(`Application_main_codes/`)과는 따로 있고, 앱 기능·라우팅·배포에 영향을 주지 않는다.

> **2026-09-28 새 버전** — 앱이 서연 UI(초록·종이색, 하단 탭 5개)로 바뀌어 영상도 새로 만들었다.
> 길이(50초)·배경음악·효과음 방식·큰 움직임의 시각은 예전 판(2026-09-20)과 같다. 예전 영상 파일은 `out/구버전_2026-09-20/`에 그대로 있다.

- 중심 메시지: **검정고시 다음, 대학까지. 혼자 막막하지 않도록, 검고담임.**
- 폰 안의 화면은 전부 **배포된 앱(https://gumgomentor.vercel.app)을 2026-09-28에 찍은 실제 화면**이다(main `02eeb14`).
- 광고용으로 새로 그린 것은 **장면 3의 네 걸음 공간**(홈의 '정보 준비·대학 찾기·원서 준비·결과 확인' 막대가 폰 밖 길과 정거장 카드로 펼쳐지는 부분)과 마지막 캠퍼스 그림뿐이다. 정거장 이름·설명은 앱 홈·로드맵의 글자와 같다.
- 글꼴은 앱과 같은 **Pretendard**, 색은 앱 `src/sy/sy.css`의 값을 그대로 쓴다.

## MP4 만들기

```bash
node tools/render-mp4.mjs
```

`out/검고담임_광고_50초_1080p.mp4` (무음, H.264, 30fps)가 생긴다. 실시간 녹화가 아니라 **한 프레임씩 시간을 옮겨 찍어서** 컴퓨터가 느려도 끊기지 않는다. 약 1분 40초 걸린다.
이 맥에 이미 있는 것만 쓴다: Google Chrome, ffmpeg, Playwright(npx 캐시). 새로 설치하지 않는다.

## 소리 (배경음악 + 효과음)

```bash
python3 tools/make-audio.py     # 소리를 처음부터 다시 만들고 MP4까지 합친다 (약 30초)
python3 tools/check-audio.py    # 큐 시점·음량·영상 불변 점검
python3 tools/audio-map.py      # 소리를 눈으로 보는 그림 → out/audio/소리지도.png
```

- **기준 파일은 `audio-cues.json` 하나다.** 여기만 고치고 `make-audio.py`를 다시 돌리면 미리보기(HTML)와 MP4 소리가 같이 바뀐다.
- 배경음악: Pixabay **Minimal Corporate Inspiration**(alexrockbeat) — 무료·상업적 사용 가능·출처 표기 불필요·Content ID 미등록. 자세한 조건은 [assets/audio/SOURCES.md](assets/audio/SOURCES.md).
  곡의 4.8초부터 50초를 쓴다(100BPM 마디선에 맞춤). 곡이 열리는 지점이 영상 14.4초(공간이 펼쳐지는 순간)에 오게 맞췄다.
- 효과음 25개는 전부 `tools/make-audio.py`가 계산해서 만든다. 내려받은 효과음 파일은 없다.
- 소리를 넣지 않은 곳: 합격을 축하하는 듯한 소리, FAQ 메시지 수신음, 45.3초 이후 QR 화면(잔향과 음악만 남는다).

### 바꾸고 싶을 때 (audio-cues.json)

| 바꿀 것 | 어디 |
|---|---|
| 전체 음악 크기 | `bgm.gainDb` (숫자가 작을수록 작아짐) |
| 구간별 음악 크기 | `bgm.automation` — `[영상 시간, 상대 dB]`. 예: 정보를 읽는 26~34초는 -2dB |
| 음악 시작 위치 | `bgm.startInTrack` (곡 안에서 몇 초부터 쓸지) |
| 효과음 위치·크기 | `sfx` 배열의 `t`(초)와 `db`(최대 크기, 0이 가장 큼). 종류는 `type` |
| 전체 음량 목표 | `target.lufsI`, `target.truePeakDb` |

### 지금 값

- 전체 음량 **-17.9 LUFS**, 최대 피크 **-1.5 dBTP**, 다이내믹 **7.1 LU** (2026-09-28 판, 예전 판 -17.9 / -1.5 / 7.0)
- 48kHz 스테레오 · 최종 오디오 AAC 254kbps (`assets/audio/ad-mix-50s.m4a` — 미리보기와 MP4가 같은 파일을 쓴다)
- 스템: `out/audio/bgm-50s.wav`(음악만) · `out/audio/sfx-50s.wav`(효과음만) · `out/audio/mix-50s.wav`(최종)

## 사실 표현 — 이렇게 지켰다

- **합격 판정처럼 보이는 화면은 쓰지 않았다.** '나와 맞는 대학'(안정·적정·소신·도전 5단계)은 넣지 않았다. 목록의 '지원 가능·지원 수월'과 전형의 '가능'은 **검정고시로 지원할 수 있는지**를 뜻하는 앱 표시 그대로다.
- 점수 계산을 **AI 합격 예측으로 소개하지 않았다.** 광고 문구에 'AI'라는 말을 쓰지 않았다.
- **커뮤니티 글은 앱의 시연용 예시 글(가상 닉네임)**이라 화면 옆에 '시연용 예시 글'을 달았다.
- **쪽지는 시연 기능이다(이 기기에만 저장, 실제 센터로 가지 않음).** 쪽지 쓰는 화면에 예시 문장을 적어 찍었고 보내지는 않았다. 광고에는 '쪽지는 시연 기능 · 예시 문장'을 단다.
- 꿈드림 센터 이름·주소는 공식 자료에서 앱이 보여 주는 그대로다(서울특별시 꿈드림센터).
- 학생 이름·개인정보 없음. 시작 질문은 '고3 나이 · 서울 · 꿈드림 아직 · 이미 검정고시를 봤어요'로 찍었다.
- 캠퍼스는 목표의 상징으로만 두고, 합격을 뜻하는 문구·표시는 없다. 스토어 출시 전이라 다운로드 배지는 넣지 않았다.
- 폰 아래에 '실제 앱 화면' 표시를 달아, 광고용 공간 연출(장면 3)과 구분했다.
- 화면 속 날짜·D-day(홈의 '원서 D-98')는 **2026-09-28 기준 캡처**다.
- 긴 화면(대학 목록·대학 정보)은 하단 탭을 숨기고 길게 찍은 뒤, 광고에서 앱처럼 위 제목줄과 하단 탭(홈 화면에서 잘라 온 것)을 제자리에 덮었다.

## 내레이션 — 넣지 않았다 (2026-09-28 판)

- 동근님 지시: "필요하면 넣고, 굳이 안 넣어도 되면 넣지 말 것". **넣지 않았다.**
- 이유: ① 장면마다 두 줄 카피가 메시지를 다 전한다. ② EXPO 부스에서 반복 재생하는 영상이라 소리가 잘 안 들리는 환경을 전제로 했다. ③ 예전 판과 소리를 같게 하라는 지시 — 내레이션을 넣으면 음악을 2~3dB 낮추는 구간이 생겨 소리가 달라진다.
- 넣게 되면: 예전 판 README(git `a8bbe03`)의 대본 형식을 참고해 장면별 대사를 새 카피에 맞게 다시 쓰고, `audio-cues.json`의 `bgm.automation`에 낮추는 구간을 더한다. TTS 음성은 이용 조건(상업·공개 게시 가능 여부)을 먼저 확인한다.
