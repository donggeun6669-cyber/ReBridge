# 검고담임 광고 영상 (EXPO·발표용)

50초 · 1920×1080 · 자동 재생 HTML 모션그래픽. 서비스 앱(`Application_main_codes/`)과는 따로 있고, 앱 기능·라우팅·배포에 영향을 주지 않는다.

- 중심 메시지: **검정고시 다음, 대학까지. 혼자 막막하지 않도록, 검고담임.**
- 폰 안의 화면은 전부 **배포된 앱(https://gumgomentor.vercel.app)을 2026-09-19에 찍은 실제 화면**이다.
- 광고용으로 새로 그린 것은 **장면 3의 로드맵 공간**(바닥 위로 길과 정거장 카드가 펼쳐지는 부분)과 마지막 캠퍼스 그림뿐이다. 정거장 이름·설명은 앱 로드맵 화면의 글자와 같다.

## MP4 만들기

```bash
node tools/render-mp4.mjs
```

`out/검고담임_광고_50초_1080p.mp4` (무음, H.264, 30fps)가 생긴다. 실시간 녹화가 아니라 **한 프레임씩 시간을 옮겨 찍어서** 컴퓨터가 느려도 끊기지 않는다. 약 1분 40초 걸린다.
이 맥에 이미 있는 것만 쓴다: Google Chrome, ffmpeg, Playwright(npx 캐시). 새로 설치하지 않는다.

## 소리 (배경음악 + 효과음)

```bash
python3 tools/make-audio.py     # 소리를 처음부터 다시 만들고 MP4까지 합친다 (약 30초)
python3 tools/check-audio.py    # 큐 시점·음량·영상 불변 점검
python3 tools/audio-map.py      # 소리를 눈으로 보는 그림 → out/audio/소리지도.png
```

- **기준 파일은 `audio-cues.json` 하나다.** 여기만 고치고 `make-audio.py`를 다시 돌리면 미리보기(HTML)와 MP4 소리가 같이 바뀐다.
- 배경음악: Pixabay **Minimal Corporate Inspiration**(alexrockbeat) — 무료·상업적 사용 가능·출처 표기 불필요·Content ID 미등록. 자세한 조건은 [assets/audio/SOURCES.md](assets/audio/SOURCES.md).
  곡의 4.8초부터 50초를 쓴다(100BPM 마디선에 맞춤). 곡이 열리는 지점이 영상 14.4초(공간이 펼쳐지는 순간)에 오게 맞췄다.
- 효과음 25개는 전부 `tools/make-audio.py`가 계산해서 만든다. 내려받은 효과음 파일은 없다.
- 소리를 넣지 않은 곳: 합격을 축하하는 듯한 소리, FAQ 메시지 수신음, 45.3초 이후 QR 화면(잔향과 음악만 남는다).

### 바꾸고 싶을 때 (audio-cues.json)

| 바꿀 것 | 어디 |
|---|---|
| 전체 음악 크기 | `bgm.gainDb` (숫자가 작을수록 작아짐) |
| 구간별 음악 크기 | `bgm.automation` — `[영상 시간, 상대 dB]`. 예: 정보를 읽는 26~34초는 -2dB |
| 음악 시작 위치 | `bgm.startInTrack` (곡 안에서 몇 초부터 쓸지) |
| 효과음 위치·크기 | `sfx` 배열의 `t`(초)와 `db`(최대 크기, 0이 가장 큼). 종류는 `type` |
| 전체 음량 목표 | `target.lufsI`, `target.truePeakDb` |

### 지금 값

- 전체 음량 **-17.9 LUFS**, 최대 피크 **-1.5 dBTP**, 다이내믹 **7.0 LU**, 클리핑 없음
- 48kHz 스테레오 · 최종 오디오 AAC 254kbps (`assets/audio/ad-mix-50s.m4a` — 미리보기와 MP4가 같은 파일을 쓴다)
- 스템: `out/audio/bgm-50s.wav`(음악만) · `out/audio/sfx-50s.wav`(효과음만) · `out/audio/mix-50s.wav`(최종)

| 시간 | 장면 | 카피 | 화면 |
|---|---|---|---|
| 0–6초 | 문제 제시 | 검정고시 다음, / 대학은 어떻게 준비하지? | 밝은 공간에 '대학·점수·원서·서류' 종이 카드가 떠 있고, 질문 쪽으로 천천히 모인다 |
| 6–12초 | 검고담임 등장 | 다음 단계가 보이도록. | 폰이 올라오고, 카드가 홈 화면의 단계 이름(내 점수·대학 찾기·원서·서류) 자리로 날아가 앱 화면으로 정리된다. '내 로드맵 보기'를 누른다 |
| 12–23초 | 로드맵 | 지금 내게 필요한 준비를, / 순서대로. | 홈 화면의 4단계 점과 선이 **폰 밖으로 이어지고**, 바닥이 기울며 길이 된다. 정거장 카드 4개가 바닥에서 일어서고 카메라가 길을 따라간다. '지금 여기(내 점수)' 카드로 다가간다 |
| 23–34초 | 점수와 대학 탐색 | 내 점수의 반영 방식부터, / 대학별 지원 조건까지. | 정거장 카드가 그대로 폰 화면이 된다 → 예시 점수 입력·평균(참고용) → 대학 탐색(필터·가나다순) → 감리교신학대학교 → 전형 카드를 폰 밖으로 꺼내 '검정고시 지원 가부 · 가능', '검정고시 점수를 내신 등급으로 환산해서 반영' 강조 |

| 43–50초 | 브랜드 마무리 | 검정고시에서 대학까지. / 검고담임. | 폰 속 단계 선이 캠퍼스 그림까지 이어지고, 로고·QR(검고담임 둘러보기)이 남는다. **45.3~49.4초(4.1초) 정지** 후 배경으로 사라져 처음과 이어진다 |

## 사실 표현 — 이렇게 지켰다

- **예시 점수**(96·92·95·97·94·98)는 화면 옆에 '예시 점수'로 표시했다. 평균 95.33점 → 추정 4등급은 앱이 계산한 그대로이고, 앱의 '(참고용 · 대학별 환산표는 달라요)' 문구도 보인다.
- **합격 판정처럼 보이는 화면은 쓰지 않았다.** 점수를 넣은 뒤의 '나와 맞는 대학'(안정·적정 칸수)과 대학 상세의 '안정 지원!' 문구가 뜨는 상태는 찍지 않고, 점수를 넣기 전 상태의 대학 화면을 썼다.
- 대학 탐색은 앱 그대로 **'335개 대학 · 가나다순' + 필터** 흐름이다.
- 점수 계산을 **AI 합격 예측으로 소개하지 않았다.** 광고 문구·내레이션에 'AI'라는 말을 쓰지 않았다(점수 엔진은 규칙 기반).
- '담임에게 물어보기'는 **자주 묻는 질문 목록**만 보여 준다. 실시간 상담·교사 답변처럼 꾸미지 않았다.
- **커뮤니티(시연 모드)는 넣지 않았다.** 홈 화면 타일에 이름만 보인다.
- 학생 이름·개인정보 없음. 시작 질문은 '고3 나이 · 서울'로 찍었다.
- 캠퍼스는 목표의 상징으로만 두고, 합격을 뜻하는 문구·표시는 없다. 스토어 출시 전이라 다운로드 배지는 넣지 않았다.
- 폰 아래에 '실제 앱 화면' 표시를 달아, 광고용 공간 연출(장면 3)과 구분했다.
- 화면 속 날짜·D-day(예: 수능 D-61, 원서 마감 9월 11일)는 **2026-09-19 기준 캡처**다.
