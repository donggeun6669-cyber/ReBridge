## ③-1. 입시 정보 제공 — "검정고시 점수로 맞는 대학 찾기"

> **핵심 메시지**: 검정고시 점수만 넣으면, 내게 맞는 대학과 **합격 가능성**, 검정고시생이 챙겨야 할 전형·서류까지 한 번에.

### (1) 내 정보 입력 (간단하게)
검정고시 점수만 있으면 시작. 모르는 항목은 비워도 됨.
- **검정고시**: 합격 회차(1회/2회/아직), 합격 연도, **6과목 점수**(국·수·영·사·과·한국사, 과목당 100점) → 입력 즉시 **평균·추정 등급** 표시
- **질문 5개**: 희망 지역 / 관심 계열 / 수능 응시 여부 / 고교 재학 이력 / 해외고 이력
- (수능 볼 예정이면) 모의고사 등급 입력 → 논술 전형 **수능 최저 충족 여부** 판정에 사용
- 안심 문구: "입력한 정보는 이 기기에만 저장돼요. 로그인 필요 없어요."

> 📷 [여기에 **내 정보 입력(프로필)** 화면 캡처]

### (2) 추천 결과 — "나와 맞는 대학" (수시 / 논술 / 정시 탭)
점수를 넣으면 **합격 가능성이 높은 순(가능성순)**으로 정렬해서 보여줌.

- **수시 탭**: 지원 가능한 대학 목록 + 각 대학 **칸수 게이지**(합격 가능성). 검정고시 비교내신 예측이 불가능한 최상위권 11곳은 "상위권 N곳 제외"로 **투명하게** 표시.
- **논술 탭** (검정고시생에게 특히 유리): **검정고시 유리도 별점**으로 분류
  - ★★★ 논술 100%·역산형 (내신 영향 거의 없음 — 최우선 추천)
  - ★★ 논술 80~90% (내신 소폭 반영)
  - ★ 혼합형 (모집요강 확인)
  - + 각 전형 **수능 최저 충족/미달/확인** 뱃지
- **정시 탭**: 수능 볼 예정일 때만, 지원 자격 안내.
- **필터/정렬**: 지역·전형·안정도·4년제/전문대 필터, 합격가능성순/가나다순 정렬.

> 📷 [여기에 **추천 결과(수시 탭, 칸수 게이지)** 화면 캡처]
> 📷 [여기에 **논술 탭(별점 분류)** 화면 캡처]

### (3) 합격 가능성 = "칸수 게이지" (진학사式)
내 점수와 작년 합격선을 비교해 **5단계**로 표시:

| 단계 | 의미 |
|---|---|
| **안정** | 작년 합격선보다 여유 있어요 |
| **적정** | 작년 합격선과 비슷한 수준이에요 |
| **소신** | 조금 부족하지만 노려볼 만해요 |
| **도전** | 아직 합격선까지 거리가 있어요 |
| **어려움** | 지금 점수로는 많이 부족해요 |

- **담임 한 줄 코치**: "작년 합격선까지 환산점수 N점 부족해요. **과목당 약 M문제** 더 맞히면 닿아요." — 부족분을 **풀어야 할 문제 수**로 번역해 체감하기 쉽게.

### (4) 검정고시 특화 분석 (이 앱만의 강점)
- **비교내신 환산**: 검정고시 점수를 대학이 "내신 등급"으로 바꾸는 방식. 대학별 공식(등급표·점수표·산출식 등 **5가지 케이스**)을 그대로 적용하고, **"계산 근거 보기"**로 단계별 환산 과정과 공개 원문까지 보여줌.
- **검정고시 적합도**: 합격 확률이 아니라 **"지원하기 좋은 정도"**(지원 수월/지원 가능/조건 확인/지원 불가). 합격선 자료가 없어도 항상 제공. 근거 3축 = 전형 성격 + 비교내신 공개 여부 + 수능 최저 유무.
- **전형별 제출서류 체크리스트**: 전형 유형에 맞는 서류 안내. **자기소개서는 2024학년도 폐지** 반영, 학종은 "학생부 대체서식"으로 안내.

### (5) 대학 상세 화면
대학별로 **담임 한마디** 요약 + 전형별 카드(칸수·작년 합격선·수능최저·면접·모집인원·비교내신 근거·제출서류). 검정고시 **지원 가능 / 조건부 / 불가**를 나눠서 보여줌.

> 📷 [여기에 **대학 상세(전형 카드 펼침)** 화면 캡처]

### (6) 정직한 데이터 표시
"작년(2025) 9등급제 입결로 추정한 **참고용 예상**이며, 2028학년도는 5등급제로 제도가 달라 실제와 차이가 있을 수 있어요" — **없는 정보는 자물쇠로 표시**하고 지어내지 않음.

## ③-2. 자주 하는 질문 → 멘토 연결 — "담임에게 물어보기"

> **핵심 메시지**: 혼자 막막해하지 않게 — **검색으로 풀고, 안 풀리면 진짜 사람(멘토)에게 바로 연결**.

화면 한 곳에서 **3단 구조**로 동작:

### ① 검색형 FAQ (입시 용어·궁금증 검색)
- 검색창: "무엇이 궁금해요? (예: 수능 안 봐도 돼요?)"
- **사람이 미리 정리한 14개 주제**를 키워드로 매칭해 카드로 보여주고, 누르면 상세 가이드로 이동.
- **AI가 답을 생성하지 않음 → 환각(잘못된 정보) 0.**
- FAQ 주제(14개): 전형이 뭐예요? / 검정고시도 수시 돼요? / 비교내신이 뭐예요? / 수능 최저가 뭐예요? / 수시 vs 정시 / 수시 몇 개까지 / 원서 언제·어떻게 / 면접에서 뭘 물어봐요? / 수능 등급은 어떻게 / 모집요강 보는 법 / 합격증명서 vs 성적증명서 / 나이스 온라인 신청 / 100점이면 교과 되나요? / 논술이 왜 유리해요?

### ② 사람 멘토에게 직접 질문 (에스컬레이션)
- "검정고시로 대학 간 선배·멘토가 직접 답해드려요. **모르면 지어내지 않고, 진짜 사람에게 연결**해드릴게요."
- 버튼: "멘토에게 직접 물어보기" → (멘토 Q&A 창구 연결)

### ③ 능동 안내 ("지금 너에게")
- 내 로드맵을 읽어 **지금 시기에 챙겨야 할 할 일**을 먼저 띄워줌. (검색하지 않아도 담임이 먼저 알려주는 느낌)

> 📷 [여기에 **담임에게 물어보기(검색 FAQ + 멘토 카드)** 화면 캡처]

### (참고) 입시 용어 가이드

## ③-3. 담임 역할 = "내 로드맵" ★ 서비스의 핵심 차별점

> **핵심 메시지**: 학교 밖이라 챙겨줄 담임이 없는 청소년에게, **앱이 담임선생님처럼** 검정고시부터 대학 등록까지 일정과 할 일을 관리.

### (1) 개인 맞춤 타임라인 (검정고시 ~ 대학 등록)
프로필(점수 보유 여부·수능 계획·오늘 날짜)에 따라 단계가 **자동으로 구성**됨. 주요 단계:
1. 검정고시 응시 → 2. 합격증명서 받기 → 3. **비교내신 확인 & 목표 대학 좁히기** → 4. 수시 원서 접수(최대 6장) → 5. 수능 응시(볼 경우) → 6. 면접·논술 → 7. 합격 발표 & 등록 → 8. 정시 지원(수시 불합격 시·선택)
- 각 단계마다 **할 일**, **용어 설명**, **"자세히 알아보기"(가이드 연결)** 제공.

### (2) "지금 내가 뭘 해야 할 때일까?"
- 오늘 날짜 기준으로 지난 단계는 **완료**, 다가오는 첫 단계를 **"지금 여기"**로 자동 표시.
- 맨 위에 **"다음 할 일" + D-day + 구체적 할 일**을 크게 강조.
- 상단 인트로: "지금 너는 여기 있어요 / 다음에 뭘 언제 해야 하는지 같이 챙길게요."

> 📷 [여기에 **내 로드맵 타임라인** 화면 캡처]

### (3) 개인 맞춤 "내 상황" 요약
- 점수가 있으면 **전체 대학을 훑어** "지금 점수로 **안정 N · 적정 N · 소신 N곳**이 있어요"처럼 요약.
- "가능성순으로 보기", "관심 대학 N곳" 같은 맞춤 버튼 제공.

### (4) 목표 대학까지 "부족 점수"
- 관심(북마크)한 대학마다 **합격선까지 몇 점/몇 문제 부족한지** 표시.

# 섹션 ⑤ 신뢰성 · 설계 원칙

발표에서 신뢰를 주는 차별 포인트로 강조하면 좋은 내용:

- **환각 없음**: 자주 하는 질문은 **사람이 미리 정리한 가이드**로만 답하고, 모르면 **진짜 멘토에게 연결**. AI가 입시 정보를 지어내지 않음.
- **데이터 정직성**: 합격선·비교내신 자료가 없으면 자물쇠로 "지금은 구하기 어려운 정보"라고 솔직히 표시. "합격 확률"과 "지원하기 좋은 정도"를 명확히 구분.
- **검정고시 최신 규정 반영**: 자기소개서 폐지(2024), 2026년 2회차 합격자의 나이스 온라인 연동 차단(등기우편 제출) 등.
- **개인정보 보호**: 로그인 없이, 모든 정보는 내 기기에만 저장.
