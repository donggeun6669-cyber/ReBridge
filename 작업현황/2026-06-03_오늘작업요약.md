## 1. UI/UX 개편 — "우다다" 제거, 진학사/메가式 점진적 공개

기존 화면이 요청하지 않은 정보까지 카드에 쏟아내던 문제를 정리.

- **대학 탐색(ExploreScreen)**: 카드당 태그 나열(검정고시 N전형·비교내신 환산표·작년 합격선)을 제거. 이제 **로고 · 대학명 · 한 줄 위치 · 헤드라인 신호 1개**(칸수 게이지 또는 검정고시 가능 배지)만 노출.
- **나와 맞는 대학(ResultsScreen)**: 카드마다 붙던 `reflection` + "지금 할 일" 풀문장 덤프 제거 → **대학명 · 위치 · 신호 1개 · 전형 한 줄**로 슬림화.
- **대학 상세(DetailScreen)**: 완전 재작성. 요약(전형명·칸수 게이지·검정고시 친화도·한 줄 코치)은 항상 보이고, 합격선/전형요소/비교내신/전형방법/제출서류는 **탭하면 펼쳐지는** 구조. 상단 **담임 한마디** 패널이 점수 기준으로 종합 코칭.

## 2. 점수 엔진 & 칸수 분석 (scoreEngine.js)

- `evaluateAdmission()` : 검정고시 평균 → 추정 등급 → 2025 합격선과 비교 → 부족 평균점수·과목당 문항수 산출.
- `admissionChance()` : 5단계 **칸수式 게이지**(안정/적정/소신/도전/어려움) 반환.
- `comparativeAvailability()` : 비교내신 환산 자료의 **유무·구할 수 있는지**를 정직하게 분류(numeric/prose/deferred/none/block).
- **공유 컴포넌트 `ChanceGauge.jsx`** 신설 → 상세·탐색·결과 3개 화면이 동일한 칸수 게이지 사용(`compact` 모드는 리스트 카드용).

## 3. 자료 부재 UI (원칙 구현)

- 수능위주 전형 → "수능 기준 전형 — 검정고시 평균으로 비교 어려움".
- 합격선 없는 전형 → 자물쇠 아이콘 + "작년 합격선 자료가 없어요 — 공개된 자료에 없어요. 검정고시 입결을 따로 공개하지 않는 대학이 많아, 지금은 구하기 어려운 정보예요."
- → **"없다"는 사실 + "구할 수 없다"는 사실**을 둘 다 명시.

## 4. 데이터 결손 보강 — patch_D 병합 (`merge_2028_patchD.py`)

Codex가 추출한 `admissions_2028_patch_D.json`(60개 대학)을 병합.

| 항목 | 변화 |
| --- | --- |
| comparative_2028.json | **132 → 187개** (신규 55, korea·yonsei는 잘못된 캠퍼스→본교로 교체) |
| └ 숫자 환산표(numeric_table) | **34 → 75개** |
| admissions_2028.json | 1304 → 1364행 (patch_D `_patch:'D'` 태그) |

- 빈 comparativeGrade 3건은 **추측 주입 금지** 원칙대로 lookup 미반영.
- additive 병합(기존 130개 무회귀) → 앱에서 신규 대학(예: 서강대) "비교내신 환산표 있음" 자동 노출 확인.
